# Repository and knowledge rules

- `content/` is generated and ignored; authoritative sources live elsewhere.
- Reuse Quartz 5, Korean locale, local fonts, offline graph assets, and existing packaging scripts.
- Use a shared stable ID across Markdown, JSONL, relationships, and validation reports.
- Provide indexes by screen, market, feature, task intent, and troubleshooting symptom.
- Keep source hashes and exact page, sheet, or row provenance.
- Validate broken relations, duplicate IDs, retrieval aliases, size outliers, and external network requests.
- Use `.node-version`, `package-lock.json`, and `uv.lock` for reproducibility.
- Never push, publish, or create releases without an explicit request.
