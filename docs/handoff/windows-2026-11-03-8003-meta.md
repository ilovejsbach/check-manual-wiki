작성: 윈도우 CHECK PC 세션. 브랜치 `session/windows-8003-meta`. 맥이 받아서 병합·반영한다.

> **푸시 상태: 보류.** 이 브랜치는 윈도우 PC에 로컬 커밋만 있다. 자동 권한 분류기가 공개 저장소로의 푸시를
> 두 번 거부했다(앱 내부 구조 데이터 포함). 사용자가 확인한 뒤 직접 푸시하거나 `git push` 권한 규칙을
> 추가해야 맥이 받을 수 있다. 푸시 전에 아래 "공개 여부" 판단이 필요하다.

## 한 줄 요약

8003 「데이터항목 검색」 화면의 원천 데이터를 **로컬 설치의 SQLite(`xlp_meta.sqlite`)에서 통째로 추출**했다.
화면을 클릭해서 읽는 방식은 앱에 입력이 전달되지 않아 쓰지 못했고, 파일을 읽는 방식으로 대체했다.

## 확인된 사실 (8003 화면 캡처와 DB 행을 대조)

- 항목코드 = `FID_LIST_TBL.FID`. 15001 현재가, 15472 대비, 15004 등락률, 15006 등락구분 등 화면 행이 DB와 일치.
- 시장코드 = `MID_LIST_TBL.MID`. 001 장내종목, 168 국내기타지수, 169 경제지표, 170 KRX커스텀지수가 화면과 일치.
- CH_Type = `MID_FID_TBL.DATA_TYPE`. 19=UINT, 3=INT, 4=LNLN, 17=UCHAR(화면 행 대조). 1, 2, 18, 20은 미확인.
- 항목 그룹(FGID) 36종, 데이터 종류(SID) 125종은 위키에 아직 없는 새 분류다.

## 맥이 판단할 것

1. **엑셀 항목코드표와의 관계.** 저장소 항목 노드 18,944개 중 5,016개만 DB에 있다. DB에만 있는 FID가 14,547개(실시간·시세 계열로 추정, 미확인)다. 저장소에만 있는 13,928개는 경제금융·재무 계열로 추정(미확인). 이름 불일치 1,844건의 상당수는 항목코드표 이름 끝 `*` 차이.
2. **온톨로지 반영 방식.** 키는 `check:item:<코드>`를 유지하면 되는지, 시장(MID)·그룹(FGID)을 새 노드로 둘지. 새 관계(`item → market`)가 필요하다. 명세 13종에 없다.
3. **공개 여부.** 이 레포는 PUBLIC이다. 추출물은 앱 내부 구조(MID 정의명 `MID_KSP_JONG`, 데이터 형식·길이, 내부 연산 테이블)를 포함한다. **`main`에 합치기 전에 공개해도 되는지 사용자 확인이 필요하다.** 이 브랜치는 그 확인 전 상태로 올렸다.

## 아직 못 한 것 / 막힌 것

- **`사용가능함수`(RTD, CT, CH, CTS) 열.** tick/intra/history 플래그로는 재현되지 않는다(15009 시가와 15020 체결량은 플래그가 같은데 화면 표기가 다르다). 8003 화면의 우클릭 메뉴(엑셀 내보내기 등)로 직접 받으면 풀릴 가능성이 크다(사용자 제안).
- **화면 조작 불가.** CHECK 앞으로 가져오기와 캡처는 되지만 클릭·우클릭이 전달되지 않았다. 커서가 요청한 좌표로 가지 않고 다른 곳으로 되돌아간다. 입력 주체가 따로 있거나 앱이 주입 입력을 막는 것으로 보이며 원인은 미확인.
- `상세` 탭, 콤보(함수, 조회주기), 검색 결과 변화는 미관찰.
- 다른 로컬 파일은 아직 열어 보지 않았다: `CheckXL\system\xlp_issue_local.sqlite`(21MB, 종목 마스터로 추정), `Master\screen_info_table.mst`(화면 번호 목록으로 추정, TR 후보 170개 정리에 쓸 수 있음), `wwwroot\app\codemaster.js`, `system\Excel\*wizard_fid.ini`(엑셀 마법사 FID 목록, 평문).
- 전체 재생성(`regenerate_all.py`)은 돌리지 않았다. `check-e2e` 폴더가 이 PC에 없다.

## 환경 메모

- `uv`는 pyenv 심이라 셸에서 `$env:PYENV_VERSION='3.11.9'`를 지정해야 동작한다(전역 설정은 안 바꿈).
- 이 PC는 야간 작업을 위해 화면 끄기(AC)를 "안 함"으로 바꿨고 화면보호기·절전은 유지 프로세스가 막고 있다. 원래 값: AC 화면끄기 1800초, 화면보호기 1200초(암호 없음).
