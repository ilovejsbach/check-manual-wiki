### 재촬영 판단

- `clock_overlay_detected`인 4107, 4205, 3065, 3527, 1379, 4206, 6448, 1201은 오버레이가 실제 값이나 열을 가린 경우가 있어 재촬영이 필요하다.
- 1300에는 단일 루트 `screen.png` 대신 상태별 캡처가 있으며, 기본 화면은 `states/analysis/14-기본/screen.png`에서 확인했다.
- CHECK 실행 창은 접근성 트리로 읽혔지만 화면 캡처 채널이 반복해서 시간 초과되었고 화면번호 입력 요소의 클릭 좌표도 제공되지 않았다. 따라서 이번 실행에서는 안전한 읽기 전용 범위 안에서 실시간 기간·종류 변경과 재촬영을 수행하지 못했다.

## 열린 질문

- `knowledge.jsonl`과 `e2e-observations.jsonl`에 공개되는 `check-e2e/golden/...` 내부 증거 경로를 삭제할지 일반화할지는 사용자 결정이 필요하다.
- `researched` 68건 기대치와 실제 62건의 차이 6건은 원본 정의·출처가 누락된 것인지, 수집 대상 변경으로 감소한 것인지 확인해야 한다. 공식 근거 없이 상태를 승격하면 안 된다.
- Quartz 검증을 완료하려면 `npx`가 있는 환경에서 동일 커밋으로 `uv run python scripts/regenerate_all.py --site`를 다시 실행해야 한다.
