# 미매핑 보강 후보 — 옵션

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 1건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 1건, procedure 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: 거래소로부터 금일 파생 시세 데이터 수신할 대 지연이 있다 연락 받음. 이러한 이유로 1) 체크에서도 파생 데이터 수신에 지연이 있었는지 2) 거래소로부터 해당 데이터 수신할 때 네트워크 mb 문의
- 당시 대응 기록: 1) 지연 있었다 안내 2) 12mb 안내
- 증거 위치: `20260916!row:3190`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
