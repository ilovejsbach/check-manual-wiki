# 주의사항 — 달러원 선물환 계산기의 롱테너 결제일은 실시간 엑셀 추출이 불가한가요?

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

달러원 선물환 계산기의 롱테너 결제일은 실시간 엑셀 추출이 불가한가요?

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 롱텀의 경우 실제 벤더사에서 실시간으로 받고 있지 않고 IRS, CRS로 Swap Point를 자체 생성하고 있어 결제일 포함 실시간 제공 데이터가 아니므로 화면 내에서 계산이 가능합니다. 참고로 실시간 추출의 경우 화면에서 Alt키를 눌렀는데 데이터부분에 빨간점이 생기는 부분만 해당 기능이 제공됩니다. 감사합니다.

## 연결된 화면·기능

연결 키가 없습니다.
