# 주의사항 — CHECK API로 ETF 괴리율 모니터링과 알람을 구축 중인데, 개발과 테스트로 사용량이 많아 시연 중 API 한도에 도달…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

CHECK API로 ETF 괴리율 모니터링과 알람을 구축 중인데, 개발과 테스트로 사용량이 많아 시연 중 API 한도에 도달할까 우려되어 당일 하루만 일 사용량을 추가 할당받을 수 있는지 문의했습니다.

## 당시 대응

관련 요청은 담당 부서 전화로 문의하도록 안내했습니다. 08:40 이후에 전화하라고 전했으며, 추가 할당 여부 자체는 기록되지 않았습니다.

## 연결된 화면·기능

연결 키가 없습니다.
