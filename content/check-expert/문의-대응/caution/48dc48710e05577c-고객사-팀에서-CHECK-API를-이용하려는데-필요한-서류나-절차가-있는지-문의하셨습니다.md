# 주의사항 — 고객사 팀에서 CHECK API를 이용하려는데 필요한 서류나 절차가 있는지 문의하셨습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

고객사 팀에서 CHECK API를 이용하려는데 필요한 서류나 절차가 있는지 문의하셨습니다.

## 당시 대응

CHECK API는 전용 사이트로 제공되며, 권한 부여 후 체크 단말 9032 화면에서 인증키를 발급받아야 합니다. 공식 문의 채널로 CHECK 단말 ID, 사용자명과 연락처, CHECK API BASIC 신청 문구를 보내면 권한을 부여하고 유선으로 추가 설명하기로 했습니다.
