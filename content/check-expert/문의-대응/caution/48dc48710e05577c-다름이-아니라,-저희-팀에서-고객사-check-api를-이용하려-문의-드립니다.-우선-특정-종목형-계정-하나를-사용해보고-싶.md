# 주의사항 — 다름이 아니라, 저희 팀에서 고객사 check api를 이용하려 문의 드립니다. 우선 특정 종목형 계정 하나를 사용해보고 싶…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

다름이 아니라, 저희 팀에서 고객사 check api를 이용하려 문의 드립니다. 우선 특정 종목형 계정 하나를 사용해보고 싶은데, 혹시 필요한 서류나 절차가 있을까요?

## 당시 대응

CHECK API 서비스의 경우 특정 종목.고객사.co.kr 사이트를 통해 제공 드리고 있으며, 사용을 위해서는 저희 쪽에서 권한을 부여 드린 후 체크 단말 9032 화면에서 인증키를 발급 받으셔야 합니다. 공식 문의 채널 메일 주소로 - CHECK 단말 ID - 사용자명 + 연락처 - CHECK API BASIC 신청합니다. 상기 내용을 보내주시면 권한 부여 진행 드리도록 하겠습니다. 관련하여 잠시 후 유선으로 추가 설명 드리겠습니다.
