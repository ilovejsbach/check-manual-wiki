# 공식 문서 연결 대기 — 넷클라이언트

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 28건
- 상태: `candidate` / `unmapped`
- 후보 유형: tip 23건, faq 2건, troubleshooting 2건, caution 1건, procedure 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: 단말 2대 중 한 대에서만 구글 접속이 되지 않는다고 문의했습니다.
- 당시 대응 기록: 해당 단말은 넷클라이언트 정책이 누락되어 있었습니다. 정책 반영은 고객사 요청 사항이므로, 정책 해지가 필요하면 고객사에 문의하도록 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 고객사 담당자가 다른 회사로 이직한 뒤 메신저 접속이 되지 않는다는 문의입니다.
- 당시 대응 기록: 넷클라이언트 정책을 삭제한 뒤 메신저 접속이 정상적으로 되는 것을 확인했습니다. 이직 전 소속에 적용된 정책이 접속을 막고 있던 상황으로 보입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 체크 단말에서 네이버와 구글 등 외부 사이트 접속이 되지 않는다는 문의였습니다.
- 당시 대응 기록: 타사 정책이 단말에 반영되어 접속이 막혀 있었으며, 이를 삭제한 뒤 정상 접속이 확인되었습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 고객사 담당자 요청으로 넷클라이언트 웹차단 적용을 해제해 달라고 요청했습니다.
- 당시 대응 기록: 웹차단 정책을 해제했으며 당일 오후 5시에 다시 적용될 예정이라고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: 고객사 요청으로 특정 단말의 웹차단 설정을 해제해 달라고 요청했습니다.
- 당시 대응 기록: 해당 단말의 웹차단 설정을 해제했으며, 당일 오후 5시에 다시 적용될 예정이라고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 6

- 고객 질문·증상: 기관에 설치된 CHECK 단말 5대의 웹차단 해제를 요청했습니다.
- 당시 대응 기록: 5대 단말의 웹차단 설정을 해제했으며 추후 다시 적용할 예정이라고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 7

- 고객 질문·증상: 출장소 단말에서 USB 차단을 해제해 달라는 요청입니다. USB 사용이 막혀 있어 해제가 필요한 상황이었습니다.
- 당시 대응 기록: 요청에 따라 USB 차단 해제를 완료했습니다. 해제 처리 후 별도 추가 조치는 기록되지 않았습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 8

- 고객 질문·증상: 고객사 요청으로 단말을 교체하면서 해당 단말에 차단 정책을 적용해 달라는 요청입니다.
- 당시 대응 기록: 다른 단말과 동일하게 해당 단말에도 차단 정책을 적용했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 9

- 고객 질문·증상: 넷클라이언트 에이전트가 설치되어 있지 않아 설치를 요청했습니다.
- 당시 대응 기록: 원격 접속으로 넷클라이언트 에이전트 설치를 완료했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 10

- 고객 질문·증상: 고객사 요청으로 특정 단말의 인증서를 업데이트하기 위해 웹차단 해제를 요청했습니다.
- 당시 대응 기록: 웹차단을 해제한 뒤 인증서 업데이트를 마치고 다시 차단을 설정하는 순서로 처리했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 11

- 고객 질문·증상: 단말의 윈도우 업데이트가 되지 않아 차단된 웹사이트의 차단 해제를 요청했습니다.
- 당시 대응 기록: 요청하신 대로 단말에서 차단되어 있던 웹사이트의 차단을 해제하는 작업을 완료했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 12

- 고객 질문·증상: 특정 도메인 사이트를 허용 목록에 추가해 달라고 요청했습니다.
- 당시 대응 기록: 요청한 사이트 주소를 단말에서 접근할 수 있도록 추가하는 작업을 완료했다고 회신했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 13

- 고객 질문·증상: 기관 단말의 화이트리스트에 여러 증권사 등 외부 사이트 주소를 추가해 달라고 요청했습니다.
- 당시 대응 기록: 요청한 사이트 주소들을 기관 단말 화이트리스트에 추가하여 적용을 완료했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 14

- 고객 질문·증상: 고객사가 특정 단말에 대해 웹차단 해제 설정을 요청했습니다.
- 당시 대응 기록: 웹차단을 해제해 드렸으며, 당일 오후 5시 30분경 차단을 다시 적용할 예정이라고 안내했습니다. 일시적인 해제 후 재적용되는 방식입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 15

- 고객 질문·증상: 기관 체크 단말에서 고객사의 특정 웹 사이트에 접근할 수 있도록 설정해 달라고 요청한 문의입니다.
- 당시 대응 기록: 요청한 사이트에 접근할 수 있도록 단말 설정을 완료했다고 처리 결과를 안내했습니다. 별도의 원인 설명은 기록되어 있지 않습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 16

- 당시 대응 기록: 요청에 따라 해당 단말의 웹차단 설정을 해제하였고, 해제 작업이 완료되었음을 확인한 사례입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 웹 차단을 해제하고 당일 오후 5시에 다시 적용하기로 했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
