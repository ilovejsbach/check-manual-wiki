# 공식 문서 연결 대기 — 해외

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 10건
- 상태: `candidate` / `unmapped`
- 후보 유형: procedure 8건, faq 7건

## 대표 사례

### 후보 1

- 고객 질문·증상: 상장 폐지된 선물의 과거 일중 데이터를 볼 수 있는 화면이 있는지 문의했습니다.
- 당시 대응 기록: 상장 폐지된 선물은 체크 프로그램에서 확인하기 어렵다고 안내했습니다.
- 증거 위치: `20260916!row:3154`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 미국 종목 데이터의 입수 주기를 TR6330 기준으로 문의했습니다.
- 당시 대응 기록: 정규장 데이터만 입수되며 15분 지연시세로 제공된다고 안내했습니다.
- 증거 위치: `20260916!row:3470`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 영국과 이탈리아 지수의 전일자 데이터가 보이지 않는데, 외부 단말에서는 해당 일자 데이터가 보이고 휴장일도 아닌 것 같다며 확인을 요청했습니다.
- 당시 대응 기록: 데이터 입수에 문제가 있었고 해당 일은 휴장일이 아니었습니다. 누락된 데이터를 소급 반영해 완료했다고 안내했습니다.
- 증거 위치: `20260916!row:3511`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 당시 대응 기록: 1026 화면의 성능을 개선해 개발에 반영했고, 클라이언트 이행은 예정되어 있다고 안내했습니다. 고객에게는 양해를 구하는 전화 안내를 했습니다.
- 증거 위치: `20260916!row:3636`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 대응 내용이 기록되지 않았습니다.
