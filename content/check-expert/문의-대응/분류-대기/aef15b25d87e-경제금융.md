# 공식 문서 연결 대기 — 경제금융

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 3건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 3건, procedure 2건

## 대표 사례

### 후보 1

- 고객 질문·증상: 요구불예금 수신고 잔액이 전체 은행을 포함한 데이터인지 확인을 요청했습니다.
- 당시 대응 기록: 산업은행이 포함된 예금은행 데이터이며 출처가 고객사라 자세한 산출 기준은 해당 기관 상담 창구에 문의하도록 안내했습니다. 해당 기관 사이트의 뉴스/자료>금융시장>일일 금융시장 주요지표에서 자료를 내려받을 수 있습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 2001 화면에서 보이는 기준금리 전망 수치가 실제 값과 다르다고 문의하셨고, 특정 종목에서 해당 지표를 어떻게 산출하는지 방식과 근거를 확인할 수 있는지 물으셨습니다.
- 당시 대응 기록: '현재값'이 해당 지표의 실제 값이고, 분기별 칸의 수치는 특정 종목이 산출한 전망치라서 실제와 다를 수 있습니다. 구체적 산출 방식은 공개되지 않으며, 화면 '주'에 적힌 대로 애널리스트 인사이트와 국가 간 상호작용, 경제지표 간 연관성을 반영한 글로벌 거시경제 모델 기반입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: MMF와 CMA의 잔고 추이를 볼 수 있는 화면과 해당 데이터의 출처가 어디인지 문의했습니다.
- 당시 대응 기록: 1008, 2600, 2601 화면을 안내했습니다. 출처는 매일 발표되는 금융시장 주요지표 보고서라고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
