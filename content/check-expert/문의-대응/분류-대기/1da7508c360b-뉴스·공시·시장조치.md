# 공식 문서 연결 대기 — 뉴스·공시·시장조치

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 3건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 3건, procedure 2건

## 대표 사례

### 후보 1

- 고객 질문·증상: - 화면번호 : - 문의내용 : 코미코(특정 수치)이라는 종목이 액면가가 500원에서 200원으로 2.5:1로 주식 분할 예정인데 체크 함수 특정 수치 아이템으로 조회한 가격은 54,400원으로 분할 전 가격입니다. 이러한 분할비율을 반영할 수 있는 조정 계수와 관련된 항목이 있는지 문의 드립니다.
- 당시 대응 기록: 해당정보는 KRX 에서도, CHECK에서도 제공하는 정보가 아닙니다. 분할비율을 KRX에서 보내주지 않으므로 전일종가와 당일기준가 변경비율을 활용한다 보심됩니다
- 증거 위치: `CRM데이터(PID복원)!row:478`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: - 화면번호 : check api 개발요청 - 문의내용 : check api에서 뉴스/공시 제목, 본문(/news/news/news_basic, /news/news/news_body)에서 "원문 공시 URL"도 함께 받을수있을까요?
- 당시 대응 기록: 안녕하세요. 특정 종목+ 입니다. 해당 API에서 제공하는 정보는 당사 시스템으로 수신되는 공시데이터를 기초로 하여 제공됩니다. 수신받는 원소스에서 원문 공시 URL이 존재하지않아 제공이 어려운 부분임을 양해 부탁드립니다. 감사합니다.
- 증거 위치: `CRM데이터(PID복원)!row:771`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: - 화면번호 : - 문의내용 : 안녕하세요 0113D0 같은 종목의 상관계수 위반 공시를 확인할 수 있는 화면이나 함수가 있을까요?
- 당시 대응 기록: 화면번호 6000에서, "종목" 선택 후, 종목코드 입력하시면 해당 ETF의 모든 공시를 확인하실 수 있습니다.
- 증거 위치: `CRM데이터(PID복원)!row:1086`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
