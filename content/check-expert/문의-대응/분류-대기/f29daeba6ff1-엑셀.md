# 공식 문서 연결 대기 — 엑셀

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 7건
- 상태: `candidate` / `unmapped`
- 후보 유형: procedure 4건, faq 2건, tip 2건, troubleshooting 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: DDE 파일로 NXT 특정 종목을 보고 있는데 업데이트가 되지 않고 KRX는 정상 갱신된다는 문의입니다.
- 당시 대응 기록: 현장에서 업데이트가 정상인 것을 확인했고 해당 담당자의 파일만 갱신되지 않아 담당자에게 전달했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 자체 제작한 엑셀 파일의 CLIST 함수가 업데이트되지 않는다는 문의입니다.
- 당시 대응 기록: 파일을 받아 확인한 결과 함수 자체에는 문제가 없었고, 파일을 다른 이름으로 저장하면 정상적으로 업데이트되었습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: CT 함수로 NXT 종목을 조회하는 방법을 문의했습니다.
- 당시 대응 기록: 종목코드 뒤에 코스피 종목이면 *222, 코스닥 종목이면 *223을 붙이면 된다고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 두 종목의 체결량과 거래대금을 같은 시간대 기준으로 나란히 추출하는 방법을 문의했습니다.
- 당시 대응 기록: CIS 함수를 사용하는 방법을 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: CLIST에서 ETP와 코덱스를 제외하고 코스피 지수 종목만 보는 방법을 문의했습니다.
- 당시 대응 기록: CFLTER 사용 방법을 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 6

- 고객 질문·증상: 영업팀을 통해 고객사 담당자가 요청한 건으로, 오피스 2016이 삭제되지 않는 문제를 해결해 달라는 문의입니다.
- 당시 대응 기록: 원격 접속으로 오피스 2016 삭제를 완료했습니다. 고객 단말에서 직접 삭제되지 않던 문제를 원격 작업으로 처리했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 7

- 고객 질문·증상: ETF 구성종목을 CLIST 함수로 조회하는데 과거일자를 넣으면 나오지 않는 이유를 문의했습니다.
- 당시 대응 기록: CLIST는 오늘자 기준으로만 조회되고 과거일자는 CTR로 조회됩니다. 따라서 과거 구성종목은 CTR을 사용하도록 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
