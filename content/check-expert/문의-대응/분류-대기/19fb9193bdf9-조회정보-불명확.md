# 공식 문서 연결 대기 — 조회정보 불명확

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 7건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 7건, procedure 6건, caution 1건, troubleshooting 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: CLIST함수의 그룹 지정에서 특정 업종과 특정 종목을 합쳐 한 번에 조회할 수 있는지 문의했습니다.
- 당시 대응 기록: CLIST함수는 구성목록을 가져오는 함수이므로 업종과 종목을 동시에 조회할 수 없습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 엑셀에서 =CTD("SPT","K2FA000",...) 함수가 작동하지 않는데, 날짜를 당일로 바꾸면 작동하는 원인을 문의했습니다.
- 당시 대응 기록: 해당 항목코드는 일별로 적재되는 데이터가 아니어서 특정 일자 조회가 되지 않습니다. 당일 값만 조회할 수 있으므로 날짜를 당일로 바꿀 때만 작동한 것입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 이전에 문의한 Intra투자자별SP순매수량누적추정치와 시장투자자별SPREAD순매수금액(기관계, 외국인, 개인 등) 데이터를 체크 API로 받을 수 있는지 검토를 요청했습니다.
- 당시 대응 기록: 요청 내용은 내부적으로 제공 가능 여부와 가능할 경우의 제공 일정을 파악한 뒤 안내하겠다고 답했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 첨부한 화면과 같은 내용을 API로 입수할 수 있는지 문의했습니다.
- 당시 대응 기록: 관련 내용을 유선으로 안내했습니다. 추가 내용은 해당 제공처 사이트에서도 확인할 수 있다고 알렸습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: 앞서 안내받은 방법을 시도했으나 수식 값만 바뀌고 #Name 표시로 데이터가 조회되지 않으며, 새 문서에서 새로 수식을 입력해도 같은 문제가 발생한다는 문의입니다.
- 당시 대응 기록: 대응 내용이 기록되지 않았습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 대응 내용이 기록되지 않았습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 원격으로 직접 확인하기 위해, 원격 연결이 준비되면 회신해 달라고 안내했습니다.
