# 공식 문서 연결 대기 — 체크화면

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 14건
- 상태: `candidate` / `unmapped`
- 후보 유형: procedure 7건, tip 7건, faq 3건, troubleshooting 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: 체크 화면에서 보던 화면이 사라졌다고 문의했습니다.
- 당시 대응 기록: 체크 프로그램을 최소화한 뒤 독립실행으로 되어 있는 화면의 독립실행을 취소하도록 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: CHECK를 켜 둔 채 퇴근하면 다음날 저장해 둔 화면이 모두 사라지는 문제가 있다는 문의입니다.
- 당시 대응 기록: 원격으로 기존 백업에서 화면을 복원했습니다. 이후 CHECK를 재설치하고 화면 설정을 다시 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 맵 초기화와 관련한 요청이 접수되었습니다.
- 당시 대응 기록: 별도 설명 없이 맵초기화로만 기록되어 있습니다. 구체적인 대응 절차나 이유는 기록되지 않았습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 단말 교체 후 화면 설정을 받았는데, 화면을 설정하고 저장해도 반영되지 않는다는 문의입니다.
- 당시 대응 기록: 원격으로 접속해 페이지설정의 화면 탭에서 수정을 클릭하는 방식으로 수정한 화면이 반영되도록 처리했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: CHECK 화면 배치와 설정을 처음 상태로 되돌리는 초기화 방법을 문의했습니다. 초기화를 요청하는 환경설정 관련 문의입니다.
- 당시 대응 기록: 화면 초기화는 USER초기화 설정 항목을 통해 처리하는 것으로 안내했습니다. 이 항목으로 사용자 화면 설정을 초기 상태로 되돌릴 수 있다는 대응이었습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 6

- 고객 질문·증상: 신체크로 업데이트한 뒤 화면이 너무 밝아 기존 테마로 바꿔 달라고 요청했습니다.
- 당시 대응 기록: 테마 색상을 블루로 변경해 처리했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 7

- 고객 질문·증상: 모니터를 상하로 배치해 사용 중이라 CHECK 프로그램이 상하로 표시되도록 조정해 달라고 요청했습니다.
- 당시 대응 기록: 원격 접속으로 멀티모니터 보기로 설정해 처리했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 8

- 고객 질문·증상: CHECK를 실행하면 왼쪽 상단에 로고 아이콘만 보이고 프로그램 화면이 나타나지 않는다고 문의했습니다.
- 당시 대응 기록: 원격 접속으로 프로그램 창 크기를 다시 조정하는 방식으로 대응했습니다. 창이 보이지 않는 증상에 대해 원격으로 프로그램 사이즈를 재조정한 것이 당시의 처리 내용입니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 프로그램이 축소된 상태로 실행되어 있었습니다. 창 크기를 늘려 사용할 수 있게 설정했습니다.
