# 공식 문서 연결 대기 — 펀드·ETF 구성·운용정보

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 11건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 11건, procedure 7건, caution 2건

## 대표 사례

### 후보 1

- 고객 질문·증상: ETF 순자산 총액을 CT 함수로 실시간 조회할 수 있는지, 항목코드 52로 함수가 동작하지 않는 이유를 문의했습니다.
- 당시 대응 기록: 다른 항목코드를 활용하도록 안내했습니다. 순자산총액은 전일자 데이터 기준이며 장중에는 실시간 갱신되지 않습니다.
- 증거 위치: `CRM데이터(PID복원)!row:358`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: API 사용 전에 데이터 샘플을 보고 싶은데 로그인하지 않으면 샘플 조회가 되지 않는 것 같아 조회 값 샘플을 요청했습니다.
- 당시 대응 기록: 특정 종목을 테스트도구로 조회한 결과 샘플을 제공했습니다. 테스트도구는 결과가 길면 뒷부분이 생략되고 1:1문의 입력란에도 크기 제약이 있으니 참고하라고 안내했습니다.
- 증거 위치: `CRM데이터(PID복원)!row:470`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 특정 호스트의 /etc/etf/etf_pdf 경로를 조회하면 HTTP 404 에러가 반환되어 확인을 요청한 문의입니다. 해당 경로가 정상 동작하는지 점검이 필요합니다.
- 당시 대응 기록: 대응 내용이 기록되지 않았습니다.
- 증거 위치: `CRM데이터(PID복원)!row:476`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: CLIST 함수로 ETF의 PDF 구성 종목을 불러오고 있는데, 특정 수치 종목의 수량만 추려서 뽑는 함수를 만들 수 있는지 문의했습니다.
- 당시 대응 기록: CLS 함수에는 함수빌더에서 참고할 수 있는 필터링 기능이 있지만 모든 항목에 적용되지는 않습니다. 문의하신 PDF 구성리스트에는 이 필터링이 적용되지 않습니다.
- 증거 위치: `CRM데이터(PID복원)!row:552`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: ETF 분배금 현황 화면의 데이터를 API로 받을 수 있도록 인터페이스를 만들어 달라고 요청했습니다.
- 당시 대응 기록: 해당 정보는 유료로 판매되는 정보여서 별도의 API 계약이 필요하며, 관련 요청은 담당 부서 상담 창구로 문의하도록 안내했습니다.
- 증거 위치: `CRM데이터(PID복원)!row:751`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 6

- 고객 질문·증상: CH 함수로 ETP 종가 NAV 기준 수익률과 특정 종목 기준 수익률이 단일종목 레버리지 상품에서 서로 다른 이유가 적용 시점 차이인지, 선물까지 반영된 지표인지 문의했습니다.
- 당시 대응 기록: 대응 내용이 기록되지 않았습니다.
- 증거 위치: `CRM데이터(PID복원)!row:1045`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 7

- 고객 질문·증상: 1446화면이나 1447화면의 데이터를 종목별, 날짜별로 티커와 필드, 날짜를 넣어 설정주수와 환매주수로 출력하는 엑셀 함수가 있는지 문의했습니다.
- 당시 대응 기록: CTD 함수로 특정 날짜의 항목 값을 받을 수 있습니다. 함수 하나당 항목 하나만 받으므로 설정주수와 환매주수에 각각 함수를 넣어야 하며, 형태는 =CTD("SPT","종목코드","날짜","항목코드")입니다.
- 증거 위치: `CRM데이터(PID복원)!row:1066`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 8

- 고객 질문·증상: API로 ETF의 과거 PDF 내역을 조회하는데 최근 1년치까지만 조회되어, 그 이전 데이터를 받을 수 있는지 문의했습니다.
- 당시 대응 기록: 현재는 제공이 불가능하며 고객사 요청으로 검토를 진행하기로 했습니다. 다만 제공 가능 시점은 확답하기 어렵다고 안내했습니다.
- 증거 위치: `CRM데이터(PID복원)!row:1079`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 9

- 고객 질문·증상: CHECK API로 ETF의 iNAV를 수신할 수 있는지 문의했습니다. 안내 사이트를 참고해 찾아봤으나 찾지 못했다고 합니다.
- 당시 대응 기록: ETP 지표가치는 주식-기본정보(전체)에서 확인할 수 있다고 안내했습니다. 호출 경로는 /stock/m001/basic_info_all이며 해당 조회항목으로 받을 수 있습니다.
- 증거 위치: `CRM데이터(PID복원)!row:1312`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 10

- 고객 질문·증상: 상장 ETF의 PDF를 종목별 또는 전체로 조회할 수 있는 함수가 있는지 문의했습니다.
- 당시 대응 기록: ETF의 PDF를 종목별 또는 전체로 조회하려면 CLIST 함수를 사용합니다. 호출 예시는 =CLIST("","",-1,"<값>*001","<값>","","<값>","DESC","<값>=true;") 형태입니다.
- 증거 위치: `CRM데이터(PID복원)!row:1397`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 11

- 고객 질문·증상: ETF 구성종목을 확인하려고 CLIST 함수를 쓰는데 과거 일자를 넣으면 값이 나오지 않는 현상을 문의했습니다.
- 당시 대응 기록: CLIST는 오늘 기준 조회 함수이고 과거 일자 조회는 CTR 함수로 하기 때문에, 과거 일자 구성종목은 CTR을 사용하도록 안내했습니다.
- 증거 위치: `CRM데이터(PID복원)!row:1449`
