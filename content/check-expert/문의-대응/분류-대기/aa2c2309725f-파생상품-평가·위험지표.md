# 공식 문서 연결 대기 — 파생상품 평가·위험지표

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 2건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 2건, procedure 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: 채권 선물 코드를 입력했을 때 바스켓을 구성하는 현물 채권과 그중 CTD를 API로 제공하는지, 제공하지 않으면 추가가 가능한지 문의했습니다.
- 당시 대응 기록: 요청한 데이터는 현재 API로 제공하지 않습니다. 바스켓 구성 현물 채권은 개발자와 논의가 필요하지만 API 개발이 가능할 것으로 보았고, CTD는 CHECK에서도 제공하지 않는 데이터라 API로도 제공할 수 없다고 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: KRX 지수의 전일 이론가를 확인하는 CT 함수가 무엇인지 문의했습니다.
- 당시 대응 기록: 지수에는 이론가 개념이 없으므로 해당 함수가 존재하지 않는다고 안내하고 문의 내용을 다시 확인해 달라고 요청했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

## 분류 게이트

- [ ] 화면번호·기능명·업무 용어를 추가 확인했는가
- [ ] 기존 문서 연결과 신규 문서 생성 중 적절한 경로를 결정했는가
- [ ] 공식 근거 또는 실제 동작 증거를 확보했는가
- [ ] 식별정보와 내부 전용 정보가 남아 있지 않은가
