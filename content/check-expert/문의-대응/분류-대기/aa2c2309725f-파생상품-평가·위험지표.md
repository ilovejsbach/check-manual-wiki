# 공식 문서 연결 대기 — 파생상품 평가·위험지표

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 2건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 2건, procedure 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: - 화면번호 : check api - 버전 : 신버전 - 문의내용 : API 중에 채권 선물 부분을 보고 있습니다. 현재 선물 코드를 입력해서 채권 선물 바스켓을 구성하고 있는, 현물 채권이 무엇인지, 그리고 현물 중 CTD가 무엇인지를 현재 API에서 제공하고 있나요? 그렇지 않다면 혹시 추가해주실 수 있을까요?
- 당시 대응 기록: 요청하신 데이터는 현재 API로는 제공하고 있지 않습니다. 다만, 개발자랑 논의를 해봐야 하겠지만 바스켓을 구성하고 있는 현물 채권이 어떤 것인지는 API로 개발이 가능할 것으로 생각됩니다. CTD는 현재 CHECK에서도 제공하고 있지 않는 데이터여서 API로 제공을 할 수는 없습니다.
- 증거 위치: `CRM데이터(PID복원)!row:915`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: - 화면번호 : - 문의내용 : KRX 지수의 전일 이론가를 확인하는 CT 함수는 어떤걸까요?
- 당시 대응 기록: 지수는 이론가 개념이 없습니다. 문의 확인 부탁드립니다.
- 증거 위치: `CRM데이터(PID복원)!row:1430`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
