# 공식 문서 연결 대기 — 기업

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 3건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 3건, procedure 3건

## 대표 사례

### 후보 1

- 고객 질문·증상: 당기순이익의 과거 정보를 조회할 수 있는 화면이 어디인지 문의했습니다.
- 당시 대응 기록: 7200 화면에서 당기순이익의 과거 정보를 조회할 수 있다고 화면 번호를 안내했습니다.
- 증거 위치: `20260916!row:4860`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 기업정보의 출처가 어디인지 문의했습니다.
- 당시 대응 기록: 7200 화면은 외부 제공처의 정보임을 안내했습니다. 화면마다 출처가 다를 수 있으므로 필요하면 화면번호를 확인한 뒤 다시 문의해 달라고 안내했습니다.
- 증거 위치: `20260916!row:5088`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: TR7200에서 2015년보다 과거의 재무제표를 확인할 수 있는지 문의했습니다.
- 당시 대응 기록: 해당 재무제표는 2015년까지만 제공된다고 안내했습니다.
- 증거 위치: `20260916!row:6436`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
