# 공식 문서 연결 대기 — 기업 재무·배당·컨센서스

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 6건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 6건, procedure 5건, caution 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: RTD 함수 =RTD("<값>.rtd",,"<값>","1*002")로 코스피 지수 배당을 수집하는데, 해당 값에 대응하는 단말 화면번호와 코스닥의 RTD 종목코드를 문의했습니다.
- 당시 대응 기록: 해당 배당 정보는 1144 화면에서 날짜를 바꿔 원하는 시점의 배당수익률을 확인할 수 있습니다. 코스닥의 고유 종목코드는 "1*004"입니다.
- 증거 위치: `CRM데이터(PID복원)!row:407`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: 6802, 3501 컨센서스 API를 쓰는 중, CHECK 화면의 목표주가, 투자의견, 증권사별 리포트 정보를 API로 조회할 방법이 있는지 문의했습니다.
- 당시 대응 기록: 해당 정보를 제공할 수 있는지 검토했으나 API로는 수신할 수 없다고 안내했습니다. 컨센서스 API에서는 해당 데이터를 조회할 수 없습니다.
- 증거 위치: `CRM데이터(PID복원)!row:539`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 7202 화면에서 조회되는 것처럼 특정 기업의 수정 DPS를 특정 분기 또는 특정 기준일로 CT 함수나 CTR 함수로 받아올 방법이 있는지 문의했습니다.
- 당시 대응 기록: TR 7202 재무비율 화면 관련 내용은 안내하지 않아도 된다는 요청이 있어 통합환경 설정 내용만 회신했습니다. 수정 DPS를 함수로 받는 방법 자체는 기록되어 있지 않습니다.
- 증거 위치: `CRM데이터(PID복원)!row:752`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 체크 API로 컨센서스와 IFRS 데이터를 받을 때 특정 종목의 매출액, 영업이익 같은 항목만 선택해 조회할 수 있는지, 아니면 전체를 받아 가공해야 하는지 문의했습니다.
- 당시 대응 기록: 해당 API는 안내 페이지에 나온 대로 특정 항목코드만 수신하는 구조가 아닙니다. 패키지형 데이터라 수정이 어려우므로 전체 데이터를 받은 뒤 사용자 측에서 가공해야 합니다.
- 증거 위치: `CRM데이터(PID복원)!row:790`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: API 함수로 받는 배당률이 어떤 방법론으로 산출되는지 확인할 수 있는지 문의했습니다.
- 당시 대응 기록: 해당 배당률은 고객사가 산출해 송부하는 데이터이며, 사업보고서 기준의 배당을 적용해 산출한다고 안내했습니다.
- 증거 위치: `CRM데이터(PID복원)!row:947`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
