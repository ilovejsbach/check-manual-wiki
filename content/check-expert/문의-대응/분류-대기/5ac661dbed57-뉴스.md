# 공식 문서 연결 대기 — 뉴스

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 2건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 2건, procedure 1건

## 대표 사례

### 후보 1

- 고객 질문·증상: 특정 키워드를 지정해 해당 뉴스가 나오면 알림을 받는 방법을 문의했습니다.
- 당시 대응 기록: F5 알림설정의 뉴스감시 메뉴에서 키워드를 지정해 뉴스 알림을 받을 수 있다고 안내했습니다.
- 증거 위치: `20260916!row:4725`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: TR6107에서 제공되는 뉴스콤 기사 내용을 수정할 수 있는지 문의했습니다.
- 당시 대응 기록: 기사 내용은 직접 수정할 수 없어 기사 담당자에게 삭제를 요청하는 방식으로 대응했습니다.
- 증거 위치: `20260916!row:6391`
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
