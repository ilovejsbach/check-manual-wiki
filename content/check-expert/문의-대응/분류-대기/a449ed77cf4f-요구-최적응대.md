# 공식 문서 연결 대기 — 요구-최적응대

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 2,268건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 2,250건, procedure 1,163건, troubleshooting 212건, caution 190건, tip 8건

## 대표 사례

### 후보 1

- 고객 질문·증상: 시작화면을 종료 시 화면으로 설정하면 오래전 종료한 화면들로 시작되는데, 종료 시 화면을 제대로 저장하는 방법이 있는지 문의했습니다.
- 당시 대응 기록: F5 환경설정에서 시작화면을 종료 시 화면으로 지정할 수 있지만, 비정상 종료나 오류 시 종료 직전 화면이 열리지 않을 수 있습니다. 그래서 F2 페이지저장으로 화면을 저장한 뒤 목록 우측의 시작화면 라디오버튼을 선택해 시작화면으로 지정하길 권장했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: PC를 교체한 뒤 집에서 쓰던 CHECK 접속이 되지 않아, 고객번호만 바꾸면 동일하게 접속할 수 있는지 문의했습니다.
- 당시 대응 기록: PC 교체 과정의 초기화에서 아웃도어 권한(PC 3대까지 번갈아 접속할 수 있는 권한)이 해제된 것으로 보여 권한을 재부여했습니다. CHECK를 재접속하면 적용되며, 여전히 안 되면 전화 또는 1:1 문의를 다시 등록해야 합니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 접속 관련 조치 후 사용자가 따로 할 일은 없는지 확인하는 문의입니다.
- 당시 대응 기록: 따로 할 일은 없다고 답했습니다. 사무실용 CHECK만 재접속하고 재택용 PC에서 접속이 정상인지 확인하도록 안내했으며, 접속이 안 되면 상담 창구로 연락하도록 했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 4

- 고객 질문·증상: 개별창 상단의 즐겨찾기, 독립실행, 종목코드연동 메뉴 옆에 창 복사하기 기능을 추가해 달라고 건의했습니다. 동일 창을 자주 여는데 메인창까지 가야 해 불편하다는 의견입니다.
- 당시 대응 기록: 스페이스바를 누르면 키워드검색창(화면번호 입력창)으로 커서가 바로 이동합니다. 또 F5로 '통합환경설정'을 열어 '개인설정' 탭의 '화면 단축키'에서 자주 쓰는 화면의 단축키를 지정하고, '기본설정' 탭의 '키보드 입력' → '단축키 입력'을 선택해 사용합니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 5

- 고객 질문·증상: 화면을 따로 열어 두지 않았는데도 자동등록갱신오류가 계속 뜬다고 문의한 사례입니다. 원인 확인을 요청했습니다.
- 당시 대응 기록: 사용자 환경 분석이 필요하여 설치 경로 아래 User 폴더를 압축해 전달해 달라고 요청했습니다. User 아래 Backup 폴더는 분석에 필요하지 않으므로 제거한 뒤 압축하도록 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

- 당시 대응 기록: 유선으로 안내했다고 기록되어 있으며, 구체적인 해결 내용은 기록되지 않았습니다.

- 고객 질문·증상: 현재 열려 있는 화면 구성을 그대로 고정해 두고 다음 실행 때도 유지하는 방법을 알고 싶다는 문의입니다.
- 당시 대응 기록: F5 키로 통합환경설정 > 기본설정 > 화면에서 시작화면을 없음, 종료시 화면, 사용자 지정 중 선택하면 됩니다. 또는 F2 키의 페이지 관리 화면에서 화면번호와 시작화면을 설정할 수도 있습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 14

- 고객 질문·증상: 집에서 CHECK를 실행했을 때 아이디는 입력되어 있으나 비밀번호란이 활성화되지 않고 자동로그인으로 비밀번호 오류만 반복된다고 문의했습니다.
- 당시 대응 기록: CHECK PC 다중접속(동시접속 불가, 최대 3대 실행 가능)에는 아웃도어 옵션 권한이 필요합니다. 사용자의 CHECK 단말 2대에 해당 권한을 부여했으니 재택용 PC에서 다시 실행하고, 안 되면 1:1문의나 전화로 재확인하도록 안내했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 15

- 고객 질문·증상: 예전에 신청했던 체크 모바일 어플을 9029 화면으로 확인하려 하니 팝업이 뜨며 접근이 되지 않아 그 이유와 안내를 문의했습니다.
- 당시 대응 기록: CHECK모바일은 서비스가 종료되어 현재는 추가비용 없이 BOND CHECK 앱으로 대체됩니다. 설치 안내는 TR 1000 안내사항 화면의 BOND CHECK 출시 게시글에 있습니다. 채권 중심이지만 지수와 환율도 보이며 전용메뉴에서 주식 관심종목을 연동해 쓸 수 있습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 16

- 고객 질문·증상: PC 부팅 시 자동 로그인되는데 윈도우 로그인 암호를 설정하려 하니 CHECK의 현재 암호를 요구해, 그 암호가 무엇인지 문의했습니다.
- 당시 대응 기록: 자동로그인을 해제하려면 F5키로 '통합환경설정' → '화면' → '로그인 설정'에서 '자동로그인 설정' 체크박스를 해제하면 됩니다. 요구된 암호는 기본 암호인 'check1' 등으로 안내했고, 되지 않으면 다시 연락하도록 했습니다.
