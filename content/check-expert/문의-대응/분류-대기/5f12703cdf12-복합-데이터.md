# 공식 문서 연결 대기 — 복합 데이터

> 기존 위키 화면·기능에 자동 연결되지 않은 비식별 신호입니다. 삭제하거나 임의 연결하지 않고 사람 검수 대기 상태로 보존합니다.

- 관련 신호: 3건
- 상태: `candidate` / `unmapped`
- 후보 유형: faq 3건, procedure 3건

## 대표 사례

### 후보 1

- 고객 질문·증상: 유가증권, KOSPI, ETF 각각의 일별 거래대금과 매수·매도금액, 그중 개인의 매수·매도금액을 함수나 화면으로 알 수 있는지 문의했습니다.
- 당시 대응 기록: 거래대금은 TR 1127 좌측 상단 '유가', 'KOSPI' 구분으로, 개인 구분 매수·매도는 1912와 1913 화면에서 확인합니다. 전체 ETF 거래대금은 1458 화면 '금액' 버튼 후 하단 총계(단위 백만원)이고, ETF 개인 매매는 1948 화면에서 'ETF'를 선택해 봅니다. ETF 당일 투자자 잠정치는 15:30 이후, 최종치는 18:00 이후 제공됩니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 2

- 고객 질문·증상: ETF 자금 유출입을 자산군별로 월, 연 단위로 볼 수 있는 화면과 API 신청 방법, 오프라인 단말 교육 가능 여부를 문의했습니다.
- 당시 대응 기록: 자산군별 자금 동향은 1457 화면 상단 둘째 줄에서 자산군을 고르고 일별, 주별, 월별로 기간을 설정해 봅니다. API는 1:1문의로 신청하면 선택옵션으로 추가 계약하며 먼저 승인하고 사용료는 익월부터 청구됩니다. 오프라인 교육도 가능해 희망 일정과 필요 화면을 받기로 했습니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정

### 후보 3

- 고객 질문·증상: 특정 종목의 근월물 주식옵션에서 OTM, ATM, ITM 각 구간의 콜·풋 종목코드와 전일 종가를 한 번에 알아내는 함수를 문의했습니다.
- 당시 대응 기록: CLIST 함수를 사용하면 되며, 해당 종목코드로 필터링하되 특정 행사가 구간의 선별은 조회 결과를 가지고 따로 해야 합니다. 예시는 =CLIST("", "", -1, "*012", "<값>", ...) 형태이며 정렬은 "DESC"로 지정합니다.
- 검토 과제: 연결할 기존 문서 또는 신규 문서 필요 여부 결정
