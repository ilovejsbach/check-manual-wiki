## 당시 대응

1. 3435 평가사 단가는 해당 수익률로 환산한 단가가 아니라 평가사 단가의 산술평균값 2. 그럼에도 불구하고 1/23 같은 수익률로 단가계산시 각 평가사와 매우 상이하여 현금흐름 확인 요청 -> 인포에 20회~ : 0.8 % (국고채 기초 스왑계약이 조기종료되지 않는 경우) 로 기재되어 있으며 0.8%로 세팅 발행사와 연락이 닿지않아 일단 인포맥스와 현금흐름을 일치시킴 -> 수정 후 평가사 단가와도 일치 -> 고객분께 피드백 드렸으나, 매매예정이 아닌 1/23에 CHECK 단가로 이미 매매하신 상태여서 상황을 지켜봐야 될 것 같다고 하시며 통화 종료.
