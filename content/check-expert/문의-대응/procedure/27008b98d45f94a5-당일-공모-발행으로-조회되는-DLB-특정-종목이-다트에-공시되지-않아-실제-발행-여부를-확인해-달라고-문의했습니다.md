# 사용 절차 — 당일 공모 발행으로 조회되는 DLB 특정 종목이 다트에 공시되지 않아 실제 발행 여부를 확인해 달라고 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

당일 공모 발행으로 조회되는 DLB 특정 종목이 다트에 공시되지 않아 실제 발행 여부를 확인해 달라고 문의했습니다.

## 당시 대응

확인 결과 발행사가 공모 발행 이후 거래소 측에 취소한 건입니다. 투자설명서는 발행사가 취소하지 않는 이상 TR 3026 화면 발행목록에서 계속 조회되기 때문에 공시 없이도 목록에 보입니다.
