# 사용 절차 — 체크 API로 컨센서스와 IFRS 데이터를 받을 때 특정 종목의 매출액, 영업이익 같은 항목만 선택해 조회할 수 있는지, 아…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

체크 API로 컨센서스와 IFRS 데이터를 받을 때 특정 종목의 매출액, 영업이익 같은 항목만 선택해 조회할 수 있는지, 아니면 전체를 받아 가공해야 하는지 문의했습니다.

## 당시 대응

해당 API는 안내 페이지에 나온 대로 특정 항목코드만 수신하는 구조가 아닙니다. 패키지형 데이터라 수정이 어려우므로 전체 데이터를 받은 뒤 사용자 측에서 가공해야 합니다.

## 연결된 화면·기능

연결 키가 없습니다.
