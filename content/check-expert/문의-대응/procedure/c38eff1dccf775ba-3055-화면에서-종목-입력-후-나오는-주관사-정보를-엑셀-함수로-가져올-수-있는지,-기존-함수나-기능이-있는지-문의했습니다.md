# 사용 절차 — 3055 화면에서 종목 입력 후 나오는 주관사 정보를 엑셀 함수로 가져올 수 있는지, 기존 함수나 기능이 있는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

3055 화면에서 종목 입력 후 나오는 주관사 정보를 엑셀 함수로 가져올 수 있는지, 기존 함수나 기능이 있는지 문의했습니다.

## 당시 대응

해당 화면 데이터는 함수를 사용할 수 없고, Alt키를 눌렀을 때 데이터에 빨간 점이 생기는 부분만 함수 기능이 제공됩니다. 대안으로 3052 화면에서 DCM 주관/인수 종목을 주관사별로 보거나, 3022 화면에서 채권 종류를 선택해 검색한 뒤 주관사 정보로 정렬할 수 있고, 화면 우클릭 후 전체영역 엑셀로 보내기도 가능합니다.
