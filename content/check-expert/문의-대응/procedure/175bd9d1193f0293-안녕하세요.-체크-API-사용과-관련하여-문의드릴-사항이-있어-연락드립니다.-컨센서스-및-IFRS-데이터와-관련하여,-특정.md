> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요. 체크 API 사용과 관련하여 문의드릴 사항이 있어 연락드립니다. 컨센서스 및 IFRS 데이터와 관련하여, 특정 종목을 대상으로 매출액, 영업이익 등 필요한 항목만 선택적으로 조회하거나 필터링할 수 있는 방법이 있는지 문의드립니다. API 사용 시 제공되는 파라미터나 별도의 설정을 통해 원하는 재무 항목만 수신할 수 있는 구조가 있는지, 혹은 전체 데이터를 수신한 뒤 사용자 측에서 가공해야 하는 방식인지 확인 부탁드립니다. 감사합니다

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 해당 API는 안내 페이지에 제시되어있는바와 같이 특정 항목코드만을 수신할 수 있는 구조가 아닙니다. 전체 데이터를 수신 한 뒤 담당자님께서 가공하셔야 합니다. 패키지형으로 되어있는 데이터인 관계로 요청주신 사항에 대해 수정이 불가한 부분이라 양해를 부탁드립니다. 감사합니다.
