# 사용 절차 — 메뉴 화면 저장 방법 문의드립니다.(재부팅 후 그대로 세팅)

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

메뉴 화면 저장 방법 문의드립니다.(재부팅 후 그대로 세팅)

## 당시 대응

우선 CHECK 메인프레임 상단 메뉴의 '보기' → '가상화면 선택' 또는 단축키 (Ctrl+1~10)를 누르시어 가상화면 그룹에 진입하시고, 원하시는 화면들을 각 가상화면에 열어두신 후 키보드 F2 버튼을 누르시어 '페이지 관리' 화면에 등록하여 저장을 하실 수 있습니다. 페이지 관리 화면 저장 시 '시작 화면'을 선택하시면 CHECK 실행 시 마다 저장한 화면 불러오기가 가능합니다. 가상화면에서 사용 중이신 구성을 보시려면 상단 메뉴의 '보기' → '열린화면바 보기' 버튼을 누르시면 '열린화면바'가 나오며, 마우스 오버 시 가상화면/화면번호/화면명을 상세하게 보실 수 있습니다. 혹시 화면 방문 교육이 필요하시어 추가 문의 남겨 주시면 연락 드리도록 하겠습니다.

## 연결된 화면·기능

연결 키가 없습니다.
