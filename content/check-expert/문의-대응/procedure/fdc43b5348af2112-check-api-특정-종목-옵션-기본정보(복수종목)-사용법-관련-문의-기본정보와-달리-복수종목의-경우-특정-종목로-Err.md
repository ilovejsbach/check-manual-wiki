# 사용 절차 — check api 특정 종목 옵션 기본정보(복수종목) 사용법 관련 문의 기본정보와 달리 복수종목의 경우 특정 종목로 "Err…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

check api 특정 종목 옵션 기본정보(복수종목) 사용법 관련 문의 기본정보와 달리 복수종목의 경우 특정 종목로 "Error while <값> Query" 반환되는데 혹시 추가 라이센스 신청 등이 필요한가요?

## 당시 대응

사이트에서 조회하실때에는 특정 종목를 'B특정 수치','C특정 수치' 과 같이 입력하셔서 실행하시면 조회됩니다. 파이썬 등 프로그램을 통해 조회하실때에는 각 프로그램 특성에 맞게 배열 형태로 조회하시면 되겠습니다. 해당 페이지 하단에 샘플을 보시면 "특정 종목" : ('특정 수치', '특정 수치') 으로 입력되어있는데, 여기서 각 주식종목코드를 옵션종목코드로 치환하여 입력하시면 조회가 가능합니다. 현재 조회상에 문제가 없음이 확인되었기에, 사용하시는 프로그램상 배열구조로 조회요청을 올리고 계신지 확인 부탁드립니다.
