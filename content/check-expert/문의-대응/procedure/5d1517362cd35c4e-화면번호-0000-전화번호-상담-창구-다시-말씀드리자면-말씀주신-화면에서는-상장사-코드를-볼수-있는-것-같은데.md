# 사용 절차 — - 화면번호 : 0000 - 전화번호 : 상담 창구 다시 말씀드리자면 말씀주신 화면에서는 상장사 코드를 볼수 있는 것 같은데…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

- 화면번호 : 0000 - 전화번호 : 상담 창구 다시 말씀드리자면 말씀주신 화면에서는 상장사 코드를 볼수 있는 것 같은데요, 전체라함은 CHECK 전체 입니다. 채권 발행만 하는 경우도 CHECK 기준코드가 있으니 그것도 볼수 있는 것을 말씀드렸습니다. 3015화면을 보시면 CHECK기준코드라고 보이실텐데 건설공제조합 처럼 모든 기업에 대해 화면있는지요. 참고로 3015는 기업신용등급 평가된 것만 보여줘서 없는 것이 많아서 활용할수 없네요

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 기관명, 코드, 약명에 대한 리스트를 TR 3015 기업 신용등급 추이 화면의 돋보기 전체복사를 엑셀 화면에서 보실 수 있습니다. 관련하여 유선으로 안내하였습니다. 감사합니다.
