# 사용 절차 — 3530, 3741 등 제가 사용하는 화면을 상시로 켜놓고싶은데 시스템을 종료하고 나면 제가 사용하는 화면이 모두 사라지고…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

3530, 3741 등 제가 사용하는 화면을 상시로 켜놓고싶은데 시스템을 종료하고 나면 제가 사용하는 화면이 모두 사라지고 다른 화면들이 켜져있습니다

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 재기동 시에도 선호하시는 화면 레이아웃을 저장하시려면 키보드 F2 페이지 관리창 사용을 추천 드립니다. 레이아웃 정돈 상태에서, F2 페이지관리창을 띄우시고, 신규 화면번호를 생성하시거나, 기존에 생성해두신 화면번호가 있으시다면 클릭하여 [ 수정 ] 단추를 통해 덮어쓰실 수도 있습니다. 이 때, 해당 페이지관리창 우측의 [ 시작화면 ] 단추를 선택하시면 재기동 시 해당 레이아웃이 호출되도록 하실 수 있습니다. F2 설정을 완료하셨다면, F5 [통합환경설정] - [기본설정] - [메인프레임] 하단의 [ 시작화면 ] 메뉴를 [ 사용자 지정 ] 으로 적용해두시면 완벽합니다. 감사합니다.
