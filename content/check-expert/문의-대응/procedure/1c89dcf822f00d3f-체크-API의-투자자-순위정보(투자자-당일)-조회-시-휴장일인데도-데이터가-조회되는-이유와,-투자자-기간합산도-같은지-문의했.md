# 사용 절차 — 체크 API의 투자자 순위정보(투자자-당일) 조회 시 휴장일인데도 데이터가 조회되는 이유와, 투자자-기간합산도 같은지 문의했…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

체크 API의 투자자 순위정보(투자자-당일) 조회 시 휴장일인데도 데이터가 조회되는 이유와, 투자자-기간합산도 같은지 문의했습니다.

## 당시 대응

1920 화면과 동일하게 동작하는 것으로, 휴일을 선택하면 전영업일 정보를 제공합니다. 휴장일 기간 조회도 같은 논리로 해석되며, 1920 화면에서 휴장일을 직접 선택해 확인해 보도록 안내했습니다.
