# 사용 절차 — 4576화면의 옵션거래규모하고 4611화면의 투자자별 거래규모에서 전체 의 숫자가다른이유

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

4576화면의 옵션거래규모하고 4611화면의 투자자별 거래규모에서 전체 의 숫자가다른이유

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 문의주신 TR 4576 옵션거래규모 K200 4/17 거래량('수량' 기준) 68,694 의 경우 주간 데이터를 보여주고 있으며, 4611 일별추이 화면에서 K200 4/17 의 경우 71,589 는 야간 데이터를 포함하고 있습니다. 4574 파생거래규모 화면 상단에서 '전체'를 선택하신 후 4/17 'K200옵션거래량'의 '주', '야'를 구분하여 보시면 주 : 68,694 야 : 2,895 합계 : 71,589 관련하여 도움이 되셨으면 좋겠습니다. 감사합니다.
