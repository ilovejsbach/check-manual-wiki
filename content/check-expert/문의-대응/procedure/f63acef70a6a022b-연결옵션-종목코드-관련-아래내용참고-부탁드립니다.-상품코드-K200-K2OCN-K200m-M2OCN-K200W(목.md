# 사용 절차 — 연결옵션 종목코드 관련 아래내용참고 부탁드립니다. <상품코드> K200 : K2OCN K200m : M2OCN K200W(목…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

연결옵션 종목코드 관련 아래내용참고 부탁드립니다. <상품코드> K200 : K2OCN K200m : M2OCN K200W(목) : K2WOCN K200W(월) : K2MOCN <특정 종목> OTM1 = O1, 고객사M1 = I1, ATM0 = A0 종목코드로 월요일만기 OTM1 연속월물을 가정하였을시 K2MOCNO1 이라는 종목코드가 됩니다. 제가 1월 19일에 문의 드렸던 것 관련해서 위 답변을 받았는데 우선 OTM1~4까지만 조회가 되고 OTM5는 조회가 안됩니다. 가장 심각한건 OTM1이 실제 OTM1이 아니라 훨씬 더 아래 가격으로 조회가 된다는 것인데 데이터 확인 부탁드립니다. =CIS( "<값>", "<값>", "100", "100", "30S", TRUE, "K2MOCNO1", "<값>", "DESC", "<값>=true;") 이 함수로 1월 29일자 위클리 K200 월요일만기 콜옵션 OTM1 가격을 조회했을 때 종목명은 767.5로 나오는데 체크 4511 기본시세표 화면의 값과 조회해보면 행사가 767.5가 아니라 행사가 760일 때의 값이 나오는 것으로 보입니다. 문제가 있는 것 같은데 확인 부탁드립니다.

## 당시 대응

1. 현재 연결옵션을 제공하는 범위는 OTM4 ~ 고객사M4 입니다. 따라서 OTM5 조회가 안되는 부분은 정상입니다. OTM5 이후의 조회 기능 제공 여부는 추가로 확인이 필요합니다. 2. ATM을 결정하는 기준은 전일 종가입니다. 즉, 1/29일의 ATM은 1/28일 특정 종목 종가를 기준으로 산출됩니다. 따라서 1/29일의 OTM1은 760 입니다. 참고로 해당 값은 거래소에서 제공하는 값을 사용하고 있습니다. 3. 엑셀 프리미엄에 나오는 종목명은 당일 날짜의 종목명을 제공하고 있습니다. 즉, 과거날짜를 조회하더라도 "종목명" 항목에는 1/30(금일) 기준의 종목명을 제공합니다. 기술적으로 복수날짜 조회 등의 문제가 있어서, 해당 문제 해결은 어려운 상황입니다. 양해 부탁드립니다. 추가로 문의사항 있으시면 언제든 말씀해주세요.
