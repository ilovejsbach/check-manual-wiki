# 사용 절차 — NXT에서 거래 가능한 종목 리스트 확인 가능한 화면이 있을까요?

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

NXT에서 거래 가능한 종목 리스트 확인 가능한 화면이 있을까요?

## 당시 대응

1550 전종목순위 화면에서 좌상단 C / K / N 시장선택 단추를 N으로 설정하시면 NXT에서 거래가능한 종목들만 표시 됩니다. 해당 단추 바로 옆 드롭다운 단추를 통해 유가 / 코스닥 종목들을 분류해서 확인하실 수도 있습니다.

## 연결된 화면·기능

연결 키가 없습니다.
