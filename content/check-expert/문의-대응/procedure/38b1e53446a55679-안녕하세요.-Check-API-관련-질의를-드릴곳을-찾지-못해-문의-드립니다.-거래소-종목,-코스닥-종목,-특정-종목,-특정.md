# 사용 절차 — 안녕하세요. Check API 관련 질의를 드릴곳을 찾지 못해 문의 드립니다. 거래소 종목, 코스닥 종목, 특정 종목, 특정…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요. Check API 관련 질의를 드릴곳을 찾지 못해 문의 드립니다. 거래소 종목, 코스닥 종목, 특정 종목, 특정 종목들에 대해서 종목투자자순매수 데이터를 수신받고 있습니다. /stock/m001/rank_invest 투자자 당일 API를 통해 16시에 수신을 요청 받아보고 있습니다. 이전에 위와 같이 받은 데이터들이 /stock/m001/rank_invest_date 투자자 기간 합산을 통해 받은 데이터가 상이해서 문의 드립니다. 추가적으로 API의 경우 장마감후 너무 이르게 요청하면 데이터가 0으로 수신받는걸 확인했습니다. 1. 마감이후 정확한 데이터가 언제부터 수신이 가능한지 1.1 이전 16시에 수신한 데이터가, 기간합산(당일로 설정)을 통해 받은 데이터가 왜 상이한지 2. 1923의 데이터와 위 네가지의 API 데이터가 동일한지 위 세가지 사항에 대해서 문의드립니다. 감사합니다.

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 1923 화면 아래 주석에서 안내한 바와 같이 당일 종목별투자자내역은 KRX은 15:30 이후에 첫 업데이트가 되고, 18:00 이후에 확정치가 들어옵니다. NXT의 경우 20:00 이후에 업데이트가 됩니다. '이후'라고 해놓은 이유는 고객사와 NXT에서 제공하는 시간이 조금 지연될 수 있기 때문입니다. 때문에 16시에 API로 수신한 데이터는 1차 업데이트 데이터이기 때문에 이후 변경이 될 수 있습니다. 감사합니다.
