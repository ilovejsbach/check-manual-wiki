# 사용 절차 — - 화면번호 : 로그인 - 전화번호 : 상담 창구 - 문의내용 : 추석연휴에 집에서 체크 프로그램을 실행했는데, 아이디는 제…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

- 화면번호 : 로그인 - 전화번호 : 상담 창구 - 문의내용 : 추석연휴에 집에서 체크 프로그램을 실행했는데, 아이디는 제대로 들어가 있는데, 비밀번호가 틀려서 옳게 수정해주려고 비밀번호 란에 클릭을 했는데도, 활성화가 안되고, 계속 자동로그인이 되니 비밀번호가 잘못됫다는 말만 계속 나옵니다 => 집에 가서 전화주신 대로 똑같이 따라 했는데도 안됩니다.

## 당시 대응

안녕하세요. 특정 종목+ 입니다. CHECK PC 다중접속(동시접속불가, 3대까지 접속실행 가능)을 실행하기 위해서 아웃도어 옵션권한이 필요합니다. 10/10 동일한 문의를 남겨주셔서 사용자분의 CHECK단말 2대에 아웃도어옵션 권한부여를 10/10 진행해 드렸습니다. 재택용 PC에서 CHECK재실행을 시도 하시고 진행이 안되실 경우 번거로우시겠지만 1:1문의 또는 전화(상담 창구. 담당자차장)를 주시면 다시 확인 진행해 드리도록 하겠습니다. 감사합니다.
