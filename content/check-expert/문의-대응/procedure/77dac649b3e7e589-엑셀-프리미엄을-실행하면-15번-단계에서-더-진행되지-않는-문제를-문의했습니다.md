# 사용 절차 — 엑셀 프리미엄을 실행하면 15번 단계에서 더 진행되지 않는 문제를 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

엑셀 프리미엄을 실행하면 15번 단계에서 더 진행되지 않는 문제를 문의했습니다.

## 당시 대응

USER 폴더를 백업하고 체크를 삭제한 뒤 관리자 권한으로 프로그램을 실행했습니다. 고객사에 체크 폴더 쓰기 권한 부여를 안내하고 USER 폴더를 복사해 실행했으며, 엑셀이 정상 실행되기까지 1~2일 걸릴 수 있음을 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
