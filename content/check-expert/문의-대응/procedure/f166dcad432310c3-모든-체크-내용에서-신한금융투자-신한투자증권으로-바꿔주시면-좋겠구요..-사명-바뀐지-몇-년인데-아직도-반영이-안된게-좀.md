# 사용 절차 — 모든 체크 내용에서 신한금융투자 ->신한투자증권으로 바꿔주시면 좋겠구요.. 사명 바뀐지 몇 년인데 아직도 반영이 안된게 좀…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

모든 체크 내용에서 신한금융투자 ->신한투자증권으로 바꿔주시면 좋겠구요.. 사명 바뀐지 몇 년인데 아직도 반영이 안된게 좀 놀랍네요. 그리고 리포트 작성자가 특정되어있는데도 주식전략팀 이런식으로 나가는 거도 잘 모르겠네요 신한투자증권은 주식전략팀이라는게 없습니다 에프앤가이드나 인포맥스 대비 UX가 많이 안좋은거같습니다..

## 당시 대응

먼저 불편을 드려 죄송합니다. 신한투자증권으로 변경하는 개편을 진행하도록 하겠습니다. 추가로 3500 관련해서는 신한투자증권에서 발송하시는 리포트 메일 제목에서 3500 화면의 제목과 기관, 작성자 등이 시스템에서 자동으로 입력하게 돼 있습니다. 현재 발송하시는 메일에 '신한 주식전략팀'으로 보내고 계시기 때문에 해당 명으로 작성자명이 들어가고 있습니다. (캡쳐 파일 참고) 작성자명의 경우 메일 제목에 들어가 있을 경우 인식이 되고, 본문의 PDF에만 들어가 있을 경우 인식이 안됩니다. 때문에 작성자 이름을 메일 제목에 넣으실 경우에만 작성자명이 들어가고 주식전략팀으로 넣을 경우 해당 명이 작성자명으로 들어갑니다.
