# 사용 절차 — 해당화면에서 만기일과 MSCI/FTSE리발란스날짜만 골라서 볼수 있도록 메뉴개발가능할까요

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

해당화면에서 만기일과 MSCI/FTSE리발란스날짜만 골라서 볼수 있도록 메뉴개발가능할까요

## 당시 대응

안녕하세요. 특정 종목+ 입니다. MSCI / FTSE 지수 리밸런싱 데이는 화면상에서 구현이 어렵습니다. 하지만 옵션 만기일의 경우, 엑셀을 통해서 필터하여 보실 수 있습니다. 1) 우선 1320 화면을 띄우신 후, 데이터 아무곳이나 우클릭하여 [ 전체영역 엑셀로 보내기 ]로 엑셀을 기동시켜 주세요. 2) 엑셀 시트 중 [ Y2 셀]에 다음과 같은 코드를 입력하시면, 옵션만기일 필터를 접합하시게 됩니다. =CH( "", "", -1, "D", TRUE, "K2OCNA0", "⟦[NUMBER]⟧", "DESC", "⟦[IDENTIFIER]⟧=true;") ** 여기서 K2OCNA0은 연결옵션의 종목코드이고, 특정 수치은 옵션종목의 잔존일수 항목코드입니다. 값이 1일 경우 만기일입니다. 3) 그러면 엑셀로 옮긴 1320 화면 전체에, 옵션만기일 필터가 합쳐지게 됩니다. 엑셀시트 3번행 전체를 커서로 선택하시고, 엑셀 상단리본 [ 데이터 ] - [ 필터 ] 기능을 누르시면 위 [ 잔존일수 ] 값을 기준으로 필터가 활성화 됩니다. 값 [ 1 ] 기준으로 필터를 거시면, 옵션만기일에 해당하는 자료들만 선택적으로 일괄 조회가 가능하십니다. 제가 구현해 본 만기일 필터 1320 엑셀 화면을 캡쳐하여 첨부드립니다. 도움이 되셨으면 좋겠습니다. 감사합니다.
