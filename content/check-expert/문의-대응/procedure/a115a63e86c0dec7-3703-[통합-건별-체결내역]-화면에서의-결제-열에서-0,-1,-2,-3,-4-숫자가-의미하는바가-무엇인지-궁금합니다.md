# 사용 절차 — 3703 [통합 건별 체결내역] 화면에서의 "결제" 열에서 0, 1, 2, 3, 4 숫자가 의미하는바가 무엇인지 궁금합니다

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

3703 [통합 건별 체결내역] 화면에서의 "결제" 열에서 0, 1, 2, 3, 4 숫자가 의미하는바가 무엇인지 궁금합니다

## 당시 대응

해당 거래의 결제일이 언제인지를 나타내는 숫자입니다. 숫자 앞에 "T+"문자가 생략되어 있다고 보시면 좋을 것 같습니다. 예를들어, 0이면 T+0일결제를 뜻해서 당일거래라고 보시면 되고, 1이면 T+1일결제를 뜻해서 익일거래를 의미합니다. 다만, 영업일(특정 종목 day) 기준이 아닌, 캘린더(특정 종목 day) 기준입니다. 따라서 오늘은 주말이 끼어있기 때문에, 일반적인 익일거래인 장외거래들은 '결제'열에 3으로 적힌 거래들이 많이 조회됩니다. 이용에 도움이 되셨길 바랍니다.
