# 사용 절차 — API 사용 전에 데이터 샘플을 보고 싶은데 로그인하지 않으면 샘플 조회가 되지 않는 것 같아 조회 값 샘플을 요청했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API 사용 전에 데이터 샘플을 보고 싶은데 로그인하지 않으면 샘플 조회가 되지 않는 것 같아 조회 값 샘플을 요청했습니다.

## 당시 대응

특정 종목을 테스트도구로 조회한 결과 샘플을 제공했습니다. 테스트도구는 결과가 길면 뒷부분이 생략되고 1:1문의 입력란에도 크기 제약이 있으니 참고하라고 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
