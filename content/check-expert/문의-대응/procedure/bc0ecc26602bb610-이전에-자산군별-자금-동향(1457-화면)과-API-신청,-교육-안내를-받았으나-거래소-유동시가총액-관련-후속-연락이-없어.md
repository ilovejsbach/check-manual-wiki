# 사용 절차 — 이전에 자산군별 자금 동향(1457 화면)과 API 신청, 교육 안내를 받았으나 거래소 유동시가총액 관련 후속 연락이 없어…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

이전에 자산군별 자금 동향(1457 화면)과 API 신청, 교육 안내를 받았으나 거래소 유동시가총액 관련 후속 연락이 없어 확인을 요청했습니다.

## 당시 대응

등록된 번호로 연락했으나 닿지 않아 문의로 답변했습니다. 당시 담당자가 휴가 중이어서 누락된 것으로 보이며, 문의 내용과 연락 가능한 번호를 알려 주시면 확인해 유선으로 연락하겠다고 안내했습니다.
