# 사용 절차 — 안녕하세요 API함수 파라미터 관련해서 문의드립니다. =RTD("[IDENTIFIER].rtd",,"[NUMBER]","1*…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요 API함수 파라미터 관련해서 문의드립니다. =RTD("[IDENTIFIER].rtd",,"[NUMBER]","1*002") 위 함수를 사용하여 코스피 지수의 배당을 수집하는 것으로 보입니다. 이와 관련하여 아래 내용에 대해 여쭤보고자 합니다. 1) "[NUMBER]" 에 매핑되는 CHECK EXPERT 단말기 화면번호가 무엇인지 2) 코스닥의 경우 RTD함수에 적용되는 고유 종목코드가 무엇인지

## 당시 대응

1) 1144 화면에서, 날짜를 변경하시면 원하시는 시점의 배당수익률 확인 가능합니다. 2) 코스닥의 고유 종목코드는 "1*004" 입니다
