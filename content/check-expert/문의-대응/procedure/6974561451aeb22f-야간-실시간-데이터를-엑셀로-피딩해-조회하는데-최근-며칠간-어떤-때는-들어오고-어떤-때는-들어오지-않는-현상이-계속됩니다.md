# 사용 절차 — 야간 실시간 데이터를 엑셀로 피딩해 조회하는데 최근 며칠간 어떤 때는 들어오고 어떤 때는 들어오지 않는 현상이 계속됩니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

야간 실시간 데이터를 엑셀로 피딩해 조회하는데 최근 며칠간 어떤 때는 들어오고 어떤 때는 들어오지 않는 현상이 계속됩니다.

## 당시 대응

수식과 통신 끊김 여부를 확인해야 하므로 엑셀 파일과 CHECK 로그 파일을 메일로 보내 달라고 요청했습니다. 문제가 있던 날짜 또는 일주일 정도의 로그를 첨부하면 확인 후 연락하기로 했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
