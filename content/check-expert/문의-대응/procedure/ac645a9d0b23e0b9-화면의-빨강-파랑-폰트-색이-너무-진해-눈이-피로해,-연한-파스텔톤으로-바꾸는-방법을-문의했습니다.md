# 사용 절차 — 화면의 빨강/파랑 폰트 색이 너무 진해 눈이 피로해, 연한 파스텔톤으로 바꾸는 방법을 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

화면의 빨강/파랑 폰트 색이 너무 진해 눈이 피로해, 연한 파스텔톤으로 바꾸는 방법을 문의했습니다.

## 당시 대응

도구 → 통합환경설정[F5]을 선택한 뒤 좌측 폰트 및 색상 → 테마변경에서 바꿀 수 있습니다. 단축키는 Ctrl + F1 화이트, Ctrl + F2 블랙, Ctrl + F3 블루입니다.

## 연결된 화면·기능

연결 키가 없습니다.
