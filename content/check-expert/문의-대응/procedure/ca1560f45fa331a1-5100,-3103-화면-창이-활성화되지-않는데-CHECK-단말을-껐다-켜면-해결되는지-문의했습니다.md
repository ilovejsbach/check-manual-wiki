# 사용 절차 — 5100, 3103 화면 창이 활성화되지 않는데 CHECK 단말을 껐다 켜면 해결되는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

5100, 3103 화면 창이 활성화되지 않는데 CHECK 단말을 껐다 켜면 해결되는지 문의했습니다.

## 당시 대응

CHECK 메뉴 상단 톱니바퀴 아이콘으로 통합환경설정을 열고 [기본설정] 탭의 [화면] 카테고리에서 '최대화면개수'를 현재보다 큰 값으로 바꾼 뒤 5100, 3103 화면을 다시 열도록 안내했습니다. 그래도 열리지 않으면 CHECK를 재실행하도록 했습니다.
