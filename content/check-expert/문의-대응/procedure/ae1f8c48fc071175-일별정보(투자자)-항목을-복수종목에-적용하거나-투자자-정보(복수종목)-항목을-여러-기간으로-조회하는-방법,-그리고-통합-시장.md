# 사용 절차 — 일별정보(투자자) 항목을 복수종목에 적용하거나 투자자 정보(복수종목) 항목을 여러 기간으로 조회하는 방법, 그리고 통합 시장…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

일별정보(투자자) 항목을 복수종목에 적용하거나 투자자 정보(복수종목) 항목을 여러 기간으로 조회하는 방법, 그리고 통합 시장 기준으로 API 조회가 가능한지 문의했습니다.

## 당시 대응

API 서비스는 정해진 요건대로만 조회할 수 있습니다. 일별정보(투자자) 항목의 복수종목 확대는 향후 검토하겠으나 당장은 제공이 어렵다고 안내했습니다.
