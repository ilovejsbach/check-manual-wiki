> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

유선 통화시 금감원 숫자와 동일한 값이라 했는데, 저희가 매일 금감원에서 제공받고있는 숫자랑 차이가 있습니다. ex) 2026/05/12 코스닥 특정 수치억원(금감원, 직접투자금 포함), check 특정 수치억원으로 차이가 있습니다. 6049화면의 전체,kospi, kosdaq 시가총액 - 외국인보유(b) 부분에 해당하는 api 알 수 있을까요? 그리고 외국인 국채선물 순매수 거래량 관련 api도 같이 안내 부탁드립니다.

## 당시 대응

유선 답변드린 내용처럼 금감원으로부터 따로 메일로 받는 귀사의 정보는 CHECK에서 처리하는 FIMS(금감원외국인시스템) 과 산정기준이 다를수 있습니다. check api 와 관련된 자세한 사항은 담당자담당자님께 유선 문의부탁드립니다. 상담 창구
