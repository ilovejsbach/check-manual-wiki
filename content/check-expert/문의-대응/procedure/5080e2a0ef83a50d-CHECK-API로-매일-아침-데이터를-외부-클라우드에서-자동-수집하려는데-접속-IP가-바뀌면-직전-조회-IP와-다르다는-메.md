# 사용 절차 — CHECK API로 매일 아침 데이터를 외부 클라우드에서 자동 수집하려는데 접속 IP가 바뀌면 직전 조회 IP와 다르다는 메…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

CHECK API로 매일 아침 데이터를 외부 클라우드에서 자동 수집하려는데 접속 IP가 바뀌면 직전 조회 IP와 다르다는 메시지가 나와, 사용 가능 여부와 고정 IP 등록 필요성, 권장 방법을 문의했습니다.

## 당시 대응

대응 내용이 기록되지 않았습니다.

## 연결된 화면·기능

연결 키가 없습니다.
