# 사용 절차 — 아래의 항목 체크 중에 조회 종목이 관심그룹에 바로 등록되지 않습니다. 제 관심그룹 리스트는 잘 나옵니다. 4. (NEW)…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

아래의 항목 체크 중에 조회 종목이 관심그룹에 바로 등록되지 않습니다. 제 관심그룹 리스트는 잘 나옵니다. 4. (NEW) 주식 현재가 화면에서 바로 관심등록 기능을 이용해 보세요. - 주식 현재가 창에서 ‘☆’을 클릭해 현재 조회 중인 종목을 관심그룹에 바로 등록할 수 있으며, 현재 해당 종목이 등록된 관심그룹도 표시됩니다. - 등록한 관심그룹에 해당 종목이 정확히 등록되었는지 확인해 보세요.

## 당시 대응

해당 내용은 1300에서 1370으로 연계를 해서 보셨던 경우로 관심종목은 등록이 되나, 해당 화면의 특성으로 보이지 않았던 현상입니다. 1370의 경우에는 매매금액과 수량을 입력해야 평가가 이루어 지고 종목이 표시되는 화면입니다. 유선으로 답변드린 내용 재전달드립니다. 즐겨찾기 부분은 개선진행하도록 하겠습니다.
