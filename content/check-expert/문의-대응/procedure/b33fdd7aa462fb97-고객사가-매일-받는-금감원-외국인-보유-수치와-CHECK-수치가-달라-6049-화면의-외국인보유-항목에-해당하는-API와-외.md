# 사용 절차 — 고객사가 매일 받는 금감원 외국인 보유 수치와 CHECK 수치가 달라 6049 화면의 외국인보유 항목에 해당하는 API와 외…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

고객사가 매일 받는 금감원 외국인 보유 수치와 CHECK 수치가 달라 6049 화면의 외국인보유 항목에 해당하는 API와 외국인 국채선물 순매수 거래량 API를 문의했습니다.

## 당시 대응

금감원에서 별도로 받는 수치는 CHECK가 처리하는 FIMS(금감원외국인시스템)와 산정 기준이 다를 수 있다고 안내했습니다. API 상세는 담당자에게 유선 문의하도록 안내했습니다.
