# 사용 절차 — 안녕하세요, 엑셀프리미엄 서비스 이용 중 문의드립니다. 【1. 화면 데이터를 매일 자동 갱신되는 수식으로 받고 싶습니다】 현…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요, 엑셀프리미엄 서비스 이용 중 문의드립니다. 【1. 화면 데이터를 매일 자동 갱신되는 수식으로 받고 싶습니다】 현재는 화면에서 "엑셀 프리미엄 보내기"를 하면 그 순간 값이 고정되어 붙는데, CH() 또는 CTR() 수식으로 매일 자동 갱신되게 받고 싶습니다. 1. 화면 3031 (채권 발행잔액 조회, 월간별) - 필요 항목: 전체 / 국채 / 지방채 / 특수채 / 통안채 / 금융채 / 회사채 (7개 카테고리) - 각 카테고리별 종목코드와 항목코드(FID)를 알고 싶습니다. 2. 화면 3216 (외국인 채권분류별 순투자 조회, 월간별) - 필요 항목: 국채 / 지방채 / 특수채 / 통안채 / 금융채 / 회사채 (6개 채권종류) - 각 채권종류별로 "순투자"와 "잔고" 컬럼의 종목코드와 항목코드(FID)를 알고 싶습니다. 【2. 아래 종목의 종목코드/항목코드(FID)를 알고 싶습니다】 - CAD Swap 1Y / 3Y / 5Y Basis - EUR Swap 1Y / 3Y / 5Y Basis - GBP Swap 1Y / 3Y / 5 Basis - AUD Swap 1Y / 3Y / 5Y Basis - 외국인보유채권([REDACTED_ENTITY] 발표 총계) 【3. 참고 - 이미 확인해서 정상적으로 쓰고 있는 예시】 - KRW CRS 6M: CH("","",10,"D",TRUE,"[IDENTIFIER]_PREB","[NUMBER]","DESC","...") - KRW CRS 1Y 종목코드 "[IDENTIFIER]_PREB", 항목코드 "[NUMBER]" - US IRS 6M: 종목코드 "07WUU06M", 항목코드 "[NUMBER]" 위와 같은 형태로 CAD/EUR/GBP/AUD 베이시스와 화면 3031/3216 데이터에 대응하는 종목코드·항목코드를 안내받고 싶습니다. 감사합니다.
