# 사용 절차 — 1601 화면 데이터를 API로 받을 수 있는지 문의했습니다. 해당 화면의 자료를 API 형태로 제공받을 수 있는지 확인을…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

1601 화면 데이터를 API로 받을 수 있는지 문의했습니다. 해당 화면의 자료를 API 형태로 제공받을 수 있는지 확인을 요청한 사례입니다.

## 당시 대응

해당 기능은 API 항목으로 추가해 달라고 내부에 의뢰하겠다고 안내했습니다. API를 사용 중이지 않은 고객이어서 필요하면 연락처를 남기면 별도로 안내하겠다고 했습니다.
