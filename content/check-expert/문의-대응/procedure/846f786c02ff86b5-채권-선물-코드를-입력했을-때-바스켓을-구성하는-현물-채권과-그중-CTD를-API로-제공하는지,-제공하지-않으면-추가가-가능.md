# 사용 절차 — 채권 선물 코드를 입력했을 때 바스켓을 구성하는 현물 채권과 그중 CTD를 API로 제공하는지, 제공하지 않으면 추가가 가능…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

채권 선물 코드를 입력했을 때 바스켓을 구성하는 현물 채권과 그중 CTD를 API로 제공하는지, 제공하지 않으면 추가가 가능한지 문의했습니다.

## 당시 대응

요청한 데이터는 현재 API로 제공하지 않습니다. 바스켓 구성 현물 채권은 개발자와 논의가 필요하지만 API 개발이 가능할 것으로 보았고, CTD는 CHECK에서도 제공하지 않는 데이터라 API로도 제공할 수 없다고 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
