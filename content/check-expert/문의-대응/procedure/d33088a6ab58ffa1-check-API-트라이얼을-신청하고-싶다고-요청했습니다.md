# 사용 절차 — check API 트라이얼을 신청하고 싶다고 요청했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

check API 트라이얼을 신청하고 싶다고 요청했습니다.

## 당시 대응

API 트라이얼은 최대 3일간 가능합니다. 공식 문의 채널로 기관, 성함, 연락처, PID와 원하는 서비스 요금제를 메일로 보내면 신청되며, 요금제 상세는 안내된 사이트에서 확인할 수 있습니다.

## 연결된 화면·기능

연결 키가 없습니다.

## 의미 분류
- 대표 유형: **사용 절차**
- 함께 볼 유형: 오류 해결, 사용 절차, 질문과 답변
- 업무·주제: 조회정보 없음(이용 문의)
- 공식 문서 연결: 분류 대기
- 문의 양식의 화면번호 입력값: 9032 (질문 대상 화면과 다를 수 있음)
