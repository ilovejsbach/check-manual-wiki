# 사용 절차 — 필터 추가 (배율) 1443 화면 처럼, 배율 (1배 / 2배 / 3배 / -1배 / -2배 / -3배 / 기타배율) 구분을…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

필터 추가 (배율) 1443 화면 처럼, 배율 (1배 / 2배 / 3배 / -1배 / -2배 / -3배 / 기타배율) 구분을 해주면 종목 선정 시 훨씬 편리할 것 같습니다. (그리고 무슨 이유인지, 1:1 문의하기 텍스트 입력이 잘 안되네요.)

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 1:1문의하기가 혹시 잘 안되실 경우, 문의전화를 통해 연락 부탁드리겠습니다. 이용에 불편을 드려 죄송합니다. 내년 1분기에 1:1문의하기 관련하여 개선이 예정되어있으니 참고 부탁드립니다. ETF정보는 거래소정보로부터 배율정보가 입수되고 있습니다. 하지만 ETN정보는 기초지수가 레버리지, 인버스 등 배율에 맞춰 상장되어서 거래소정보로는 배율정보가 일반(1배)로 입수되고 있습니다. 이부분에 대해서 CHECK에서도 인지하고 있어서 정보추가 방안을 검토중에 있습니다. 내년 상반기에는 당사 타서비스(ETF CHECK)에서 배율관련 구분값을 자체적으로 부여하고 있는데, 이 정보를 CHECK단말로 이관하여 보여주는 방식으로 검토중에 있습니다. CHECK화면에서 2205화면을 오픈하시면 ETF CHECK를 조회하실 수 있습니다. 왼쪽상단 메뉴에서 K-ETN을 선택하시고 레버리지/인버스를 선택하시면 각 배율별 종목들을 리스트로 확인하실 수 있습니다. 웹페이지라 데이터 활용에 어려움이 있으시겠지만, CHECK화면 개발 전까지 배율로 구분되는 종목들을 해당화면에서 확인하실 수 있으니 참고 부탁드립니다. 감사합니다.
