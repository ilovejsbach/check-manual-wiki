# 사용 절차 — 1002 세계지수종합 화면에 KOSPI, K200, KOSDAQ 외에 특정 종목 지수를 추가할 수 있나요? If so, 추가…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

1002 세계지수종합 화면에 KOSPI, K200, KOSDAQ 외에 특정 종목 지수를 추가할 수 있나요? If so, 추가하는 방법 알려주세여

## 당시 대응

안녕하세요. 특정 종목+ 입니다. TR 1002 세계지수종합 화면 왼쪽 각 '시장' 오른쪽 부분에 'v' 모양의 버튼이 있습니다. 해당 부분을 누르시면, 특정 종목 지수를 추가할 수 있는 드롭다운 메뉴가 나옵니다. 원하시는 지수를 선택하셔서 추가 사용할 수 있습니다. (※ 관련 화면 캡쳐하여 첨부하였습니다.) 감사합니다.
