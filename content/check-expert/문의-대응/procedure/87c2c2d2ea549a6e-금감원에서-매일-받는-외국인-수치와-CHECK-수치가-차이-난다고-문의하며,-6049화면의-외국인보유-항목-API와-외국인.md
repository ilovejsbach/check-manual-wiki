# 사용 절차 — 금감원에서 매일 받는 외국인 수치와 CHECK 수치가 차이 난다고 문의하며, 6049화면의 외국인보유 항목 API와 외국인…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

금감원에서 매일 받는 외국인 수치와 CHECK 수치가 차이 난다고 문의하며, 6049화면의 외국인보유 항목 API와 외국인 국채선물 순매수 거래량 API 안내를 요청했습니다.

## 당시 대응

금감원에서 별도로 받는 정보는 CHECK가 처리하는 FIMS(금감원외국인시스템)와 산정 기준이 다를 수 있다고 안내했습니다. CHECK API 관련 자세한 사항은 담당자에게 유선 문의하도록 했습니다.
