# 사용 절차 — 특정 종목의 전환가액이 현재 값으로 표시되는데, 과거 특정 시점의 전환가액으로 볼 수 있는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

특정 종목의 전환가액이 현재 값으로 표시되는데, 과거 특정 시점의 전환가액으로 볼 수 있는지 문의했습니다.

## 당시 대응

표준코드시스템에 마지막으로 입력된 값을 보여주는 구조라 특정 시점의 값으로 보여드리기는 어렵다고 안내했습니다.
