# 질문과 답변 — 파생 API의 주식선물 통계정보 중 투자자 기본 정보(복수종목)에 시간정보가 추가될 예정이라고 들었는데 개발 일정을 공유해…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

파생 API의 주식선물 통계정보 중 투자자 기본 정보(복수종목)에 시간정보가 추가될 예정이라고 들었는데 개발 일정을 공유해 달라고 문의했습니다.

## 당시 대응

주식선물 투자자 정보에 시간정보가 추가되었다고 안내하며 확인을 요청했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
