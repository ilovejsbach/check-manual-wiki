## 사용자가 겪은 상황

안녕하세요. 체크 API 사용과 관련하여 문의드릴 사항이 있어 연락드립니다. 이전에 문의드린 데이터에 대해서 Check API를 통해서 데이터를 수신을 받고 싶습니다. 향후 API를 통한 제공이 가능한지 검토 부탁드립니다. - F특정 수치^n Intra투자자별SP순매수량누적추정치 - F7435^n 시장투자자별SPREAD순매수금액(기관계, 외국인, 개인 등) 감사합니다

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 요청 주신 내용은 내부적으로 가능 여부 및 가능 시 제공일정 등을 파악하여 말씀 드리도록 하겠습니다. 감사합니다.
