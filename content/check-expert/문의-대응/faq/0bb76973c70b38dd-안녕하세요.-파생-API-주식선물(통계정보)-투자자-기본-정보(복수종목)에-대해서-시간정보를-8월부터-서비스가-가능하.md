# 질문과 답변 — 안녕하세요. 파생 API > 주식선물(통계정보) > 투자자 기본 정보(복수종목)에 대해서 시간정보를 8월부터 서비스가 가능하…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요. 파생 API > 주식선물(통계정보) > 투자자 기본 정보(복수종목)에 대해서 시간정보를 8월부터 서비스가 가능하다고 회신받았었습니다. 위 내용에 대해서 개발일정을 공유가 가능할까요? 감사합니다.

## 당시 대응

안녕하세요. 주식선물 투자자 정보에 시간정보가 추가됐다고 합니다. 확인해 보시기 바랍니다. 감사합니다.
