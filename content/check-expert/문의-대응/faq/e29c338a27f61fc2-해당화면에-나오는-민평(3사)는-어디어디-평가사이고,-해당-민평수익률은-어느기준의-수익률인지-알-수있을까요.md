# 질문과 답변 — 해당화면에 나오는 민평(3사)는 어디어디 평가사이고, 해당 민평수익률은 어느기준의 수익률인지 알 수있을까요?

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

해당화면에 나오는 민평(3사)는 어디어디 평가사이고, 해당 민평수익률은 어느기준의 수익률인지 알 수있을까요?

## 당시 대응

민평(3사): 고객사, KIS자산평가, NICE피앤아이 민평(4사): 고객사, KIS자산평가, NICE피앤아이, 에프앤자산평가 민평(3사), 민평(4사) 수익률은 위에 적힌 평가사들이 산출한 수익률을 평균한 값이며, 해당 수익률은 채권시장 마감 후, 하루에 한 번 산출이 됩니다.
