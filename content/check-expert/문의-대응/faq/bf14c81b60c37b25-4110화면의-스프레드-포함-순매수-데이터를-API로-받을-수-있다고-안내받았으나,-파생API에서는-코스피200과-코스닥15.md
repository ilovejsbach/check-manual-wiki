# 질문과 답변 — 4110화면의 스프레드 포함 순매수 데이터를 API로 받을 수 있다고 안내받았으나, 파생API에서는 코스피200과 코스닥15…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

4110화면의 스프레드 포함 순매수 데이터를 API로 받을 수 있다고 안내받았으나, 파생API에서는 코스피200과 코스닥150 선물에만 SPREAD합산순매수 항목이 있습니다. 다른 선물의 야간 투자자별 합산 데이터도 수신할 수 있는지 문의했습니다.

## 당시 대응

기술팀과 협의한 결과 다음 주부터 해당 데이터를 수신할 수 있도록 반영하기로 했다고 답변했습니다.
