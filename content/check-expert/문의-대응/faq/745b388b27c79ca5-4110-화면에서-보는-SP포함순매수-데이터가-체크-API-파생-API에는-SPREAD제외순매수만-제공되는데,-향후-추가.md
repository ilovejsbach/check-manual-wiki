> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

4110 화면에서 보는 "SP포함순매수" 데이터가 체크 API 파생 API에는 SPREAD제외순매수만 제공되는데, 향후 추가될 예정인지 문의했습니다.

## 당시 대응

개발 쪽에 추가 진행을 요청했으며 완료되면 추후 안내하겠다고 답했습니다.
