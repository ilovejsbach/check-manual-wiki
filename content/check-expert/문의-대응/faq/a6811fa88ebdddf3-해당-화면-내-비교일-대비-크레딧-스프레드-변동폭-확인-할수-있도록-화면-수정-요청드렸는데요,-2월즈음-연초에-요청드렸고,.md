# 질문과 답변 — 해당 화면 내 비교일 대비 크레딧 스프레드 변동폭 확인 할수 있도록 화면 수정 요청드렸는데요, 2월즈음 연초에 요청드렸고,…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

해당 화면 내 비교일 대비 크레딧 스프레드 변동폭 확인 할수 있도록 화면 수정 요청드렸는데요, 2월즈음 연초에 요청드렸고, 한두달 내에 반영 가능하다고 해당 담당자 분과 통화하였는데 아직 화면 개발이 되지 않은 것 같아 다시 문의 드립니다.

## 당시 대응

외화24시간 개장 관련하여 당사 인력이 대부분 투입 된 관계로 해당 개편이 약간 늦어졌습니다. 요청주신 화면은 현재 7월 16일 이행 예정이며, 7월20일부터 화면에서 확인하실 수 있습니다. 다시 한번 늦어져서 죄송한 말씀드립니다.
