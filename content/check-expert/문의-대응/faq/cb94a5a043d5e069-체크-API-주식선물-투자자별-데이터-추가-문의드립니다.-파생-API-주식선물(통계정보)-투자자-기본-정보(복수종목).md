# 질문과 답변 — 체크 API 주식선물 투자자별 데이터 추가 문의드립니다. 파생 API > 주식선물(통계정보) > 투자자 기본 정보(복수종목)…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

체크 API 주식선물 투자자별 데이터 추가 문의드립니다. 파생 API > 주식선물(통계정보) > 투자자 기본 정보(복수종목)을 통해 데이터를 수신하고 있습니다. 1. 30초주기로 업데이트 되는 데이터로 알고있습니다. 제공하는 데이터의 시간도 수신할 수 있을까요? 2. 파생 API > 주식선물(통계정보) > 투자자 주기 정보에서 제공하는 데이터 중 F특정 수치_01 INT Intra종목투자자별주체별시간1 은 무엇을 의미하는지 문의드립니다. 감사합니다.

## 당시 대응

답변이 늦어져 죄송합니다. 1번에 대해 기술팀과 협의하느라 답변이 늦어졌습니다. 1. 시간을 추가해 8월부터 서비스해드리겠습니다. 시간정보는 최근 투자자정보 제공시각입니다(30초단위 최근시간) 2. 1번과 같은의미의 투자자산출시각이며 KRX에서 투자자정보와 함께 제공하는 산출시점 정보입니다.
