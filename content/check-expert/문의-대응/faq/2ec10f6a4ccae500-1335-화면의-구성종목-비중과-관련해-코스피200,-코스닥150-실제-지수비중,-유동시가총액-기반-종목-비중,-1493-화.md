# 질문과 답변 — 1335 화면의 구성종목 비중과 관련해 코스피200, 코스닥150 실제 지수비중, 유동시가총액 기반 종목 비중, 1493 화…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

1335 화면의 구성종목 비중과 관련해 코스피200, 코스닥150 실제 지수비중, 유동시가총액 기반 종목 비중, 1493 화면의 ETF 구성종목 데이터를 API로 받을 수 있는지 문의했습니다.

## 당시 대응

1335, 1147,1148,1149 등의 지수구성비중은 KRX와 지수계약을 직접 맺은 고객에게만 제공되므로 KRX와 직접 계약해야 합니다. ETF 구성종목은 당시 API 미제공이었고 곧 제공 예정이며, API 계약은 상담 창구로 문의하도록 안내했습니다.
