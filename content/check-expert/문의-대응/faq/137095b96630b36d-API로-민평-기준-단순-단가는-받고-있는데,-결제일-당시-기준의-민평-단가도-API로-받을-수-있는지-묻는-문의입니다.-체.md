# 질문과 답변 — API로 민평 기준 단순 단가는 받고 있는데, 결제일 당시 기준의 민평 단가도 API로 받을 수 있는지 묻는 문의입니다. 체…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API로 민평 기준 단순 단가는 받고 있는데, 결제일 당시 기준의 민평 단가도 API로 받을 수 있는지 묻는 문의입니다. 체결 단가는 결제일 기준인데 민평 단가는 그렇지 않다는 내용입니다.

## 당시 대응

문의한 데이터는 현재 API로 제공하지 않는 정보입니다. 개발과 제공 가능 여부를 내부적으로 논의한 뒤 별도로 피드백하기로 했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
