# 질문과 답변 — 안녕하세요 체크 화면 4110 화면을 통해 "SP포함순매수" 데이터를 확인하고 있습니다. 체크 API > 파생 API에서는…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요 체크 화면 4110 화면을 통해 "SP포함순매수" 데이터를 확인하고 있습니다. 체크 API > 파생 API에서는 SPREAD제외순매수 데이터만 제공하는것으로 확인했습니다. 향후 해당 데이터가 체크 API에 추가되거나 제공될 예정이 있는지 문의드립니다.

## 당시 대응

개발쪽에 추가 진행 요청했습니다. 완료되는대로 추후 연락드리겠습니다. 감사합니다.
