# 질문과 답변 — 1002 화면과 5103 화면의 원달러 환율 값이 서로 다른 이유와 어느 값을 기준으로 봐야 하는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

1002 화면과 5103 화면의 원달러 환율 값이 서로 다른 이유와 어느 값을 기준으로 봐야 하는지 문의했습니다.

## 당시 대응

1002 화면은 5103 화면에서 02:00 종가를 기준으로 보여주고 있어, 5103 화면에서 해당 값으로 설정하면 같은 값이 나옵니다. 15:30 종가를 쓰려는 목적이면 5103 화면을 이용해야 하며 표기 방식은 개선을 검토하겠다고 했습니다.
