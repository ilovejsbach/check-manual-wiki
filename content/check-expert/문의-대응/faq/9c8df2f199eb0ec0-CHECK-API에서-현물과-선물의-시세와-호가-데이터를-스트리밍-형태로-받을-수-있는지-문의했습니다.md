# 질문과 답변 — CHECK API에서 현물과 선물의 시세와 호가 데이터를 스트리밍 형태로 받을 수 있는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

CHECK API에서 현물과 선물의 시세와 호가 데이터를 스트리밍 형태로 받을 수 있는지 문의했습니다.

## 당시 대응

CHECK API는 스트리밍 방식이 아니라 CHECK 단말이 제공하는 데이터 중 일부를 API로 제공하며, 호출 시점의 데이터를 반환하는 방식입니다. 자세한 사항은 안내한 API 소개 웹페이지에서 확인할 수 있다고 답했습니다.
