# 질문과 답변 — 화면 3101 하단 왼편의 국채선물 수익률이 나오지 않고 화면 4171을 포함해 에러가 많아 실시간 사용 중이라 빠른 수정을…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

화면 3101 하단 왼편의 국채선물 수익률이 나오지 않고 화면 4171을 포함해 에러가 많아 실시간 사용 중이라 빠른 수정을 요청했습니다.

## 당시 대응

확인 즉시 수정 조치를 요청했으며, 국채선물 만기 후 데이터 연결에 문제가 생긴 것으로 예상된다고 안내했습니다. 수정되는 대로 다시 연락하기로 했습니다.
