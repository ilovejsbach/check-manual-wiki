# 질문과 답변 — 주식선물 투자자 데이터의 체크 API 개발이 완료됐다고 들었으나 체크 API 페이지에서 찾지 못해 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

주식선물 투자자 데이터의 체크 API 개발이 완료됐다고 들었으나 체크 API 페이지에서 찾지 못해 문의했습니다.

## 당시 대응

해당 API를 안내 페이지의 future/m005investbasic 경로에 추가했다고 안내했습니다.
