# 질문과 답변 — CHECK API에서 국채선물 10년 12월물 코드는 되는데 3년 12월물 코드로는 데이터가 받아지지 않아 다른 코드를 써야…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

CHECK API에서 국채선물 10년 12월물 코드는 되는데 3년 12월물 코드로는 데이터가 받아지지 않아 다른 코드를 써야 하는지 문의했습니다.

## 당시 대응

국채 10년물과 3년물은 CHECK API 호출 주소가 서로 다릅니다. 고객사 사이트의 파생-API 하부 메뉴 중 국채3년물 메뉴를 참고하면 되며, 선물은 상품별로 API가 구성되어 있습니다.

## 연결된 화면·기능

연결 키가 없습니다.
