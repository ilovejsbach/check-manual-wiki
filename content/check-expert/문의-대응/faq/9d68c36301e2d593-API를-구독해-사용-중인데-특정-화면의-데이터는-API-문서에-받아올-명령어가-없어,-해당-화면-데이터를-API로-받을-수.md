# 질문과 답변 — API를 구독해 사용 중인데 특정 화면의 데이터는 API 문서에 받아올 명령어가 없어, 해당 화면 데이터를 API로 받을 수…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API를 구독해 사용 중인데 특정 화면의 데이터는 API 문서에 받아올 명령어가 없어, 해당 화면 데이터를 API로 받을 수 있는지 또는 놓친 방법이 있는지 문의했습니다.

## 당시 대응

유선으로 요청한 부분을 개발자들과 논의한 뒤 피드백하겠다고 안내했습니다. 현재 문서상 제공 여부에 대한 확정 답변은 기록되지 않았습니다.

## 연결된 화면·기능

연결 키가 없습니다.
