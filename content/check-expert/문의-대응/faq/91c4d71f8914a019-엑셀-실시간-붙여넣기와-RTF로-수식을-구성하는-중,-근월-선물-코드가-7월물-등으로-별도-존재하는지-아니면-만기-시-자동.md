# 질문과 답변 — 엑셀 실시간 붙여넣기와 RTF로 수식을 구성하는 중, 근월 선물 코드가 7월물 등으로 별도 존재하는지 아니면 만기 시 자동…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

엑셀 실시간 붙여넣기와 RTF로 수식을 구성하는 중, 근월 선물 코드가 7월물 등으로 별도 존재하는지 아니면 만기 시 자동 교체되는지 문의했습니다.

## 당시 대응

해당 종목 코드는 근월물에 해당하는 연결선물 코드입니다. 6월물이 만기되면 자동으로 7월물로 교체되어 값을 가져오므로 별도 코드가 필요하지 않습니다.

## 연결된 화면·기능

연결 키가 없습니다.
