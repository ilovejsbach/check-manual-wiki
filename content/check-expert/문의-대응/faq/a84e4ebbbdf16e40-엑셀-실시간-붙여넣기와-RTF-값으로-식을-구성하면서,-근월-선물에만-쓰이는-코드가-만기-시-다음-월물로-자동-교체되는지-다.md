# 질문과 답변 — 엑셀 실시간 붙여넣기와 RTF 값으로 식을 구성하면서, 근월 선물에만 쓰이는 코드가 만기 시 다음 월물로 자동 교체되는지 다…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

엑셀 실시간 붙여넣기와 RTF 값으로 식을 구성하면서, 근월 선물에만 쓰이는 코드가 만기 시 다음 월물로 자동 교체되는지 다른 월물용 코드가 따로 있는지 문의했습니다.

## 당시 대응

해당 코드는 근월물에 해당하는 연결선물 코드입니다. 말씀하신 대로 근월물이 만기되면 다음 월물로 자동 교체됩니다.

## 연결된 화면·기능

연결 키가 없습니다.
