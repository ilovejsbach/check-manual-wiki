# 질문과 답변 — 다름이 아니라 제가 api 신규 제공 서비스 관련해서 이메일로 문의를 드렸었는데 혹시 가능성이 있으려나해서요

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

다름이 아니라 제가 api 신규 제공 서비스 관련해서 이메일로 문의를 드렸었는데 혹시 가능성이 있으려나해서요

## 당시 대응

URL을 사용하여 제공 가능한 회원사 매매집계 데이터 활용에 대한 내용을 메일로 회신드렸습니다. ex) HOST https://특정 종목.고객사.co.kr POST /stock/m001/member_date
