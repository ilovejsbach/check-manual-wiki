# 질문과 답변 — 1601 화면과 관련된 API 파일을 받을 수 있는지 문의한 사례입니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

1601 화면과 관련된 API 파일을 받을 수 있는지 문의한 사례입니다.

## 당시 대응

API 사이트 좌측 메뉴에서 CHECK가 제공하는 API 종류를 확인할 수 있고, 주식-API>거래소종목>회원사 매매집계에서 해당 화면과 유사한 정보를 볼 수 있습니다. 문의자는 API 미이용자로 확인되어, 신청을 원하면 1:1문의나 이메일로 접수하도록 안내했습니다.
