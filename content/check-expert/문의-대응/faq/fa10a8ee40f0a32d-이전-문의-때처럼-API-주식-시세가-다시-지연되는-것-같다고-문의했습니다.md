# 질문과 답변 — 이전 문의 때처럼 API 주식 시세가 다시 지연되는 것 같다고 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

이전 문의 때처럼 API 주식 시세가 다시 지연되는 것 같다고 문의했습니다.

## 당시 대응

확인 시점에는 시세 지연이 해소되었습니다. 실시간 시세 지연은 최적화 중이지만 시스템 한계상 시세가 폭증하면 지연이 발생하며, 재발하지 않도록 로직 개선 여부를 검토 중이라고 설명했습니다.

## 연결된 화면·기능

연결 키가 없습니다.

- [ ] 원인과 해결 조치를 구분해 설명할 수 있는가
