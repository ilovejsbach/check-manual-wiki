# 오류 해결 — 같은 포트에 대해서 평가2, 평가3의 당일 수익 차이가 매우 심하게 나타나는 오류가 나옵니다. 확인 부탁드립니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

같은 포트에 대해서 평가2, 평가3의 당일 수익 차이가 매우 심하게 나타나는 오류가 나옵니다. 확인 부탁드립니다.

## 당시 대응

안녕하세요. [IDENTIFIER]+ 입니다. TR 1370 평가2 화면의 경우 화면 좌상단 'C' 선택을 하셨으나, TR 1386 평가3 화면은 'K'를 선택하셔서 차이가 나고 있는 것으로 보입니다. 버튼을 클릭하시어 같은 기준으로 조회를 하실 경우에도 이상이 있으시면 말씀 부탁 드립니다. 새해 복 많이 받으세요. 감사합니다.
