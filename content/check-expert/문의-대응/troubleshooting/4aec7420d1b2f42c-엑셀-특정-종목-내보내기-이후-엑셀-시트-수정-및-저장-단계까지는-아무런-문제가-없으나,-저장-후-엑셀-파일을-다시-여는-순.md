# 오류 해결 — 엑셀 특정 종목 내보내기 이후 엑셀 시트 수정 및 저장 단계까지는 아무런 문제가 없으나, 저장 후 엑셀 파일을 다시 여는 순…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

엑셀 특정 종목 내보내기 이후 엑셀 시트 수정 및 저장 단계까지는 아무런 문제가 없으나, 저장 후 엑셀 파일을 다시 여는 순간 특정 종목 이뜨며 기존 정보들이 다 사라지는 현상이 발생하고 있습니다. 해당 부분에 대한 도움 요청드리고자 문의 남깁니다.

## 당시 대응

특정 종목는 CHECK 서버와 연결이 안된 상태를 의미합니다. 엑셀을 모두 닫고 아래 내용 확인부탁드립니다. 1. 데이터가 있는 화면에서 [마우스 우클릭>실시간 또는 프리미엄 보내기] -> 조회가 정상인지 확인 후 저장 2. 1번에서 저장한 파일을 더블클릭하여 열기 -> 정상인지 확인 3. 2번이 조회되지 않는 다면, 1번을 실행 후 엑셀 메뉴 파일>열기로 저장파일 열었을때 정상인지 확인 => 2번까지 정상인데 만드신 파일만 오픈시 끊기는 거라면 아래메일로 파일전송 부탁드립니다. 공식 문의 채널 => 2번은 안되지만 3번으로 저장된 파일이 열린다면 첨부파일을 참고하여 엑셀프리미엄을 재설치 후 PC를 재부팅후 확인부탁드립니다. - 엑셀매니저에서 [UAC 변경]을 체크한 상태로 설치하셔야 애드인이 정상적으로 됨.
