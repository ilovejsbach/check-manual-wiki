# 오류 해결 — 안녕하세요! 혹시 체크 api 신청하려고 하는데 추가금액이 드는 서비스 인건지 알수 있을까요?

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요! 혹시 체크 api 신청하려고 하는데 추가금액이 드는 서비스 인건지 알수 있을까요?

## 당시 대응

CHECK API 서비스는 월 10만원의 추가 요금이 부과되는 부가서비스입니다. 특정 종목.고객사.co.kr 사이트에서 서비스 안내 및 현재 제공 중인 모든 API의 스펙을 확인하실 수 있습니다. 사용을 원하실 경우, 공식 문의 채널 메일주소로 PID / 사용자명 / 연락처 / " CHECK API BASIC 신청합니다. " (예시) 와 같이 보내주시면 권한부여 및 과금처리 후 사용법 안내 드리도록 하겠습니다. 감사합니다.
