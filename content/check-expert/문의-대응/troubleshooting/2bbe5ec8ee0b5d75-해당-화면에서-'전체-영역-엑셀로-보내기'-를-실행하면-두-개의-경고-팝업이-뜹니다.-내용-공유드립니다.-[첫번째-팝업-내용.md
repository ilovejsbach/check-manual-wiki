# 오류 해결 — 해당 화면에서 '전체 영역 엑셀로 보내기' 를 실행하면 두 개의 경고 팝업이 뜹니다. 내용 공유드립니다. [첫번째 팝업 내용…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

해당 화면에서 '전체 영역 엑셀로 보내기' 를 실행하면 두 개의 경고 팝업이 뜹니다. 내용 공유드립니다. [첫번째 팝업 내용] 특정 종목 32비트 프로세스에서 64비트 프로세스의 모듈에 엑세스 할 수 없습니다. [두번째 팝업 내용] 특정 종목 : 값은 null 일 수 없습니다. 매개변수이름: path 구버전에서는 해당 팝업이 뜨지 않았는데, 신버전에서는 팝업이 나와서 문의 남겨두었습니다. 확인부탁드리겠습니다. 감사합니다.

## 당시 대응

안녕하세요. 특정 종목+ 입니다. - 엑셀프리미엄설치하기 진행시 성공하는지 확인해주세요. - CHECK엑셀매니저에서 'UAC 변경 진행 여부'가 체크표시 되어있는지 확인해주세요. (첨부파일 참고, 체크하고 설치 되어야함.) - 체크 연동이 아닌 빈엑셀 실행시에도 팝업이 뜨는지 확인해주세요. 보내주신 메시지는 보통 체크와 엑셀의 계정이 사용자계정으로 연동되었을때 뜨는 내용입니다. UAC 변경을 체크한 상태에서 프리미엄을 재설치하고 재부팅하면 해결되는 경우가 많습니다. 내용 참고하셔서 확인해보시고 잘안되시면 재문의부탁드립니다. 감사합니다.
