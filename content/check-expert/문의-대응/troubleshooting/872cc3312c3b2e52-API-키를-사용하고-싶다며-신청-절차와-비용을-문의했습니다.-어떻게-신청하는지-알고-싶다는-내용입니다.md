# 오류 해결 — API 키를 사용하고 싶다며 신청 절차와 비용을 문의했습니다. 어떻게 신청하는지 알고 싶다는 내용입니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

## 당시 대응

공식 문의 채널로 신청할 API요금제, 단말PID, 사용자 성함과 전화번호를 보내면 확인 후 담당자가 연락한다고 안내했습니다. 비용은 API요금제 안내 사이트에서 확인할 수 있습니다.
