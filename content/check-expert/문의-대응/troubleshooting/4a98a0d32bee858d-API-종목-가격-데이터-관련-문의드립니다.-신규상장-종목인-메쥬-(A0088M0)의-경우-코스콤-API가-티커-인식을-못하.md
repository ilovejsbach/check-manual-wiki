# 오류 해결 — API 종목 가격 데이터 관련 문의드립니다. 신규상장 종목인 메쥬 (A0088M0)의 경우 코스콤 API가 티커 인식을 못하…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API 종목 가격 데이터 관련 문의드립니다. 신규상장 종목인 메쥬 (A0088M0)의 경우 코스콤 API가 티커 인식을 못하는거로 보입니다. 티커 끝 M0가 신규상장/전환형 특수코드라서 매핑이 안되는거로 보이는데 확인 한번 부탁드립니다. 혹시 해당 종목 0088M0이 아니라 다른식으로 호출해야할까요?

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 문자배열 처리에서 저희쪽 오류가 있었던 점 양해 부탁 드립니다. DB 패치 후 아래와 같이 수정하여 사용할 수 있습니다. 괄호 대신에, " " 으로 양끝을 묶고, ' ' 으로 종목코드를 넣으시면 됩니다. ex) "특정 종목" : ('B특정 수치','B특정 수치') → "특정 종목" : "'B특정 수치','B특정 수치'" 혹시 해보신 후 안되시면 사용중이신 코드를 공식 문의 채널 로 메일 주시면 확인 후 회신 드리도록 하겠습니다. 감사합니다.
