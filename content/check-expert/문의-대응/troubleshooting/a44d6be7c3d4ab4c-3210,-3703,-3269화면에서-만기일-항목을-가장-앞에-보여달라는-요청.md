# 오류 해결 — 3210, 3703, 3269화면에서 만기일 항목을 가장 앞에 보여달라는 요청

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

3210, 3703, 3269화면에서 만기일 항목을 가장 앞에 보여달라는 요청

## 당시 대응

1. 3210 만기일 선택이 가능하나 오토세이브가 안됨. 오토세이브나 디폴트가 만기일이었으면 좋겠다고 요청 -> 담당자에 내용 전달 2. 3703 만기일 항목이 뒤에 있으므로 ctrl+컬럼선택으로 이동 후 마우스R>컬럼정보 저장 안내 3. 3269 만기일 항목 맨 앞에 추가 요청 -> 담당자에 내용 전달 - 25/11/12(수) 15:54 고객이 통화 어렵다고 하여 재통화 예정 - 25/11/13(목) 10:26 고객이 통화 어렵다고 함 (통화불가로 완료처리)
