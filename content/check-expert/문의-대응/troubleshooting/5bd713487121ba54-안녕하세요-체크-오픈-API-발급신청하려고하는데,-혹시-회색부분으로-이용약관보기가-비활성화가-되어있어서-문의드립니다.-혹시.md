# 오류 해결 — 안녕하세요 체크 오픈 API 발급신청하려고하는데, 혹시 회색부분으로 이용약관보기가 비활성화가 되어있어서 문의드립니다. 혹시…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

안녕하세요 체크 오픈 API 발급신청하려고하는데, 혹시 회색부분으로 이용약관보기가 비활성화가 되어있어서 문의드립니다. 혹시 활성화를 시키려면 어떻게 해야할까요??

## 당시 대응

안녕하세요, CHECK API서비스는 소정의 옵션 이용료가 추가되는 부가서비스 입니다. **특정 종목.고객사.co.kr** << API 전용 홈페이지에서 제공 중인 API의 스펙을 확인하실 수 있습니다. 부가 이용료는 API BASIC의 경우 **월 10만원이며, 일일 200MB의 용량이 제공** 됩니다. 용량이 부족하실 경우 요금제를 상향하실 수 있지만, 대부분의 이용자가 BASIC 요금제를 사용 중이시므로 일반적인 사용이라면 충분하실 것으로 예상합니다. API 홈페이지를 살펴보시고, 사용을 희망하실 경우 **공식 문의 채널 << 메일주소로 CHECK PID / 사용자명 / 연락처 / " CHECK API BASIC 사용 신청합니다 "** 내용을 보내주시면 권한 부여 후 사용 설명 해피콜 드리도록 하겠습니다. 감사합니다.
