# 오류 해결 — #체험 안녕하세요. 이번 화면 및 기능 업그레이드 관련하여 개선 작업 진행해주신 노고에 감사드립니다. 전반적으로 화면이 훨씬…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

#체험 안녕하세요. 이번 화면 및 기능 업그레이드 관련하여 개선 작업 진행해주신 노고에 감사드립니다. 전반적으로 화면이 훨씬 보기 편하고 보기 쉽게 변했으며, 전체 화면과 기능들이 사용자 입장에서 체감될 정도로 개선되었습니다. 아래와 같이 주요 개선 사항과 함께 확인된 이슈/개선 요청 사항을 공유드립니다. 1. 화면 밝기 개선 * 화면이 밝아져서 숫자가 더 잘 보입니다. 2. ‘전체 영역 엑셀로 보내기’ 기능 개선 및 오류 확인 * 기존: 빈 엑셀 파일이 2~3개 열리고 마지막 엑셀에서 값이 나오거나, 시간이 오래 걸리거나, 아예 열리지 않는 경우가 종종 있었습니다. * 현재: 바로 엑셀로 값이 출력되어 업무 처리 속도가 개선되었습니다. * 다만, 오류 발생: 화면 1491에서 해당 기능 사용 시 아래 에러 메시지가 발생하며 엑셀 출력이 되지 않습니다. 피호출자가 호출을 거부했습니다. OLE 특정 종목 caught. SCODE:특정 수치 3. 프로그램 꺼짐(강제 종료) 발생 * 사용 중 “오류진단코드 보낼까요?” 라는 메시지가 출력되면서 프로그램이 종료되는 현상이 발생합니다. 5. ‘나만의 기능’ 개선 체감 * 메모, 폰트 크기, 즐겨찾기 기능이 강화되어 DIY 형태로 화면을 구성하기가 더 편해졌습니다. 6. 히트맵 기능 개선 요청 * 히트맵에서 ETF 섹터별로, ETF 순자산총액 기준 정렬/표시가 가능하면 활용도가 더 높아질 것 같습니다. 7. 전반적인 속도 개선 체감 * 전체적으로 화면 반응 속도가 빨라진 것 같습니다. 8. 8101 계절성 차트 기능 개선 요청 * 8101 계절성 차트에서 여러 종목을 동시에 비교할 수 있으면 좋겠습니다. (예: 특정 종목처럼 다중 종목 오버레이 형태)

## 당시 대응

안녕하세요. 특정 종목+ 입니다. 좋은 의견 감사드립니다. 문의주신 내용에 대해 답변을 같이 전달드리오니 참고 부탁드립니다. 2, 3 번 : 오류부분 확인하여 우선적으로 조치될 수 있도록 하겠습니다. "오류진단코드 보낼까요" 메시지가 발생될 경우, "예"를 꼭 선택해주시기 바랍니다. 오류가 발생한 시점의 파일이 전송되어 원인분석에 도움이 됩니다. 6. 히트맵 ETF선택시에 콤보버튼이 있습니다. 순자산총액으로는 없으나, 시총상위순으로 확인이 가능하오니 사용해보시기 바랍니다. 섹터까지의 세분화 된 분류는 해당 화면에서 구현의 어려움이 있어 자산별 분류를 제공하고 있습니다. 자산별 분류를 통해 확인 부탁드립니다. 8. 계절성차트는 라이브러리 문제로 여러종목 비교가 어렵습니다. 비교차트의 경우 1105화면을 사용하신 것을 추천드립니다. 감사합니다.
