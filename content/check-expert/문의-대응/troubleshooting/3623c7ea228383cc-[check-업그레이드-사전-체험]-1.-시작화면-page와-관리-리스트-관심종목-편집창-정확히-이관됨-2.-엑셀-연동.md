# 오류 해결 — [check 업그레이드 사전 체험] 1. 시작화면 page와 관리 리스트 / 관심종목 편집창 정확히 이관됨 2. 엑셀 연동…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

[check 업그레이드 사전 체험] 1. 시작화면 page와 관리 리스트 / 관심종목 편집창 정확히 이관됨 2. 엑셀 연동 기능 정상 작동함 - 6490 화면 내 데이터 엑셀로 추출해봄 3. 화면 그룹간 종목 연동 기능 이용 해봄 - 이상없음(1440화면과 8110 화면 연동해봄) 4. 주식 현재가 화면에서 관심등록 기능 이용해봄 5. 주식 현재가 화면 메모 등록 기능 이용해봄 / 이용가능했음 / 다만, 로딩 시간이 지나치게 길어서, 굳이 체크에서 사용할 필요 없다고 느낌 추가) 메모 길게 작성했을 경우, 일부 요약해서 앞부분만 보여주고 눌렀을때 메모 활성화 되는 게 더 좋을지도. 기업실적 등 긴 자료 메모해두고, 다른 메모 추가할 경우, 위에 긴 메모 때문에 스크롤 길게 해야함 6. 주식 종목 검색 시 조회 종목 관리 이용 - 추가된 기능으로서 손쉽게 관심종목 관리할 수 있게 된 것이라 판단 7. 화면 내 폰트 조정 기능 이용 - 기존의 경우, 테이블이나 화면 크기 조정시 글씨 크기 관련해서 다양한 선택지가 없어 불편했었는데, 개선됨 8. 화면 자석 기능 이용 - 기존에는 수기로 사이즈 조절해두고, 화면 구성 변경시 틈이 생기거나 하는 것을 채우려면 품이 많이 들었었음. 자석 기능 덕분에 그런 부분 개선됨 9. 신규화면 - 일부 채권 화면은 확인할 수 없었으나, 차트 관련 화면들 다양해져서 더 관찰해봐야 할 것 같음. 다만, 로딩 속도가 좀 더 느려진 느낌은 지울 수 없음 전반적으로 오류는 없어보입니다.
