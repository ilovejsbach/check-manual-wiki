# 오류 해결 — 화면을 따로 열어 두지 않았는데도 자동등록갱신오류가 계속 뜬다고 문의한 사례입니다. 원인 확인을 요청했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

화면을 따로 열어 두지 않았는데도 자동등록갱신오류가 계속 뜬다고 문의한 사례입니다. 원인 확인을 요청했습니다.

## 당시 대응

사용자 환경 분석이 필요하여 설치 경로 아래 User 폴더를 압축해 전달해 달라고 요청했습니다. User 아래 Backup 폴더는 분석에 필요하지 않으므로 제거한 뒤 압축하도록 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.

- [ ] 현재 버전에서도 같은 상황이 재현되는가

- [ ] 원인과 해결 조치를 구분해 설명할 수 있는가
- [ ] 고객·직원·기관 식별정보가 남아 있지 않은가
