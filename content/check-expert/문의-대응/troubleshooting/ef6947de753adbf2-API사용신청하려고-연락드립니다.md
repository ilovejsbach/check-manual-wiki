# 오류 해결 — API사용신청하려고 연락드립니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API사용신청하려고 연락드립니다.

## 당시 대응

안녕하세요, 체크팀입니다. API서비스의 경우 이메일로 신청을 주시면, 권한 부여 후 사용법 설명 해피콜을 진행 드리고 있습니다. ㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡ 1. PID : 특정 종목 2. 사용자명 : 담당자 과장 3. 전화번호 : 상담 창구 4. CHECK API BASIC 사용 신청합니다. ㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡㅡ 상기 내용을 공식 문의 채널 주소로 보내주시면, 권한 부여 처리 후 연락 드리도록 하겠습니다. API BASIC 서비스의 경우 월 10만원의 옵션 이용료가 기존 체크단말 요금에 합산하여 부과 됩니다. 감사합니다.
