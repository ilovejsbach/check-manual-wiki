# 오류 해결 — 엑셀 실시간 붙여넣기를 하면 엑셀에 아무것도 나오지 않고, 체크에서 F5를 누르면 EXCEL 실시간 연동이 비활성화되어 있다…

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

엑셀 실시간 붙여넣기를 하면 엑셀에 아무것도 나오지 않고, 체크에서 F5를 누르면 EXCEL 실시간 연동이 비활성화되어 있다는 문구가 표시된다고 문의했습니다.

## 당시 대응

원격으로 체크를 삭제한 뒤 관리자 권한으로 다시 설치했습니다. 기관 전산 담당에 체크 폴더 쓰기 권한 부여를 요청하고 기존 USER 폴더를 복사하도록 안내했으며, 시간이 지나 엑셀이 정상 작동함을 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
