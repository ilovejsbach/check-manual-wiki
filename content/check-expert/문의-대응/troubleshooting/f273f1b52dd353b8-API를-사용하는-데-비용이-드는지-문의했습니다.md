# 오류 해결 — API를 사용하는 데 비용이 드는지 문의했습니다.

> 비식별 문의 기록에서 추출한 검수 전 사례입니다. 당시 대응이 현재 제품의 공식 해결책임을 의미하지 않으며, 공식 매뉴얼과 재현 시험으로 확인해야 합니다.

## 사용자가 겪은 상황

API를 사용하는 데 비용이 드는지 문의했습니다.

## 당시 대응

API는 용량에 따라 Basic부터 5단계로 요금이 다르며, 고객사 사이트의 이용요금 메뉴에서 확인할 수 있습니다. API 옵션 추가가 필요하면 공식 문의 채널로 메일을 보내도록 안내했습니다.

## 연결된 화면·기능

연결 키가 없습니다.
