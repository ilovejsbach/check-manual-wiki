# 메뉴와 템플릿

## 메뉴,템플릿

- 이전메뉴 — 직전에 수행된 기능을 다시 실행 할 경우 사용합니다.
- 템플릿화면 — 기본제공되는 템플릿을 이용할 수 있습니다.
- Data 조회 — 각종 데이터조회 함수를 손쉽게 할수 있는 기능입니다.
- 종목검색 — 종목조회 및 결과를 시트로 가져올 수 있습니다.
- 항목검색 — 항목조회 및 결과를 시트로 가져올 수 있습니다.
- 함수마법사 — 함수의 인수 입력을 편리하게 할수 있는 기능입니다.
- ez차트 — 테이블 형태의 데이터를 차트로 만들 수 있는 기능입니다.
- 테이블조회 — 테이블 구조의 반복적인 함수 입력을 한번에 할수 있습니다.
- Refresh — 데이터 갱신을 범위,시트,워크북 별로 할수 있습니다.
- 설정 — 데이터 갱신을 범위,시트,워크북 별로 할수 있습니다.
- 도우미 — 옵션사항에 대한 설정을 할수 있습니다.
- 도움말 — 공지사항,자료실,버전정보를 연결합니다.
- 메뉴 사용의 편리함을 위해 툴바를 선택하여 작업 할 수 있습니다.
- 1.이전메뉴 — 5.Data조회 — 9.ez차트 — 13.도우미
- 2.실시간 시세 반연 — 6.종목검색 — 10.테이블조회 — 14.도움말
- 3.실시간 시세 멈춤 — 7.항목검색 — 11.Refresh
- 4.템플릿조회 — 8.함수마법사 — 12.설정
- 이전메뉴
- 직전에 수행된 기능을 다시 실행할 경우 사용합니다.
- 최근 10개 까지 기억합니다.
- 10개 초과시 먼저 등록된 항목이 삭제 됩니다.
- 이전메뉴에 등록된 메뉴는 재실행 해도 이전메뉴에 다시 등록되지 않습니다.
- 템플릿 화면 (단축키 :Ctr l +Shift +T)
- 엑셀 투자 정보 시스템의 편의성을 위하여 시장별로 템플릿 화면을 제공하고 있습니다.
- 원하는 템플릿 화면을 선택하여 열면 기본화면이 구성 되어 열립니다.
- 템플릿 화면을 구성하는 셀은 해당하는 수식으로 이뤄져 있으므로 함수 사용에 도움을 받을 수 있습니다.
- 템플릿 메뉴에서 원하는 템플릿을 선택하여 엑셀 파일에 열기
- 검색 기능
- 원하는 템플릿을 검색할수 있습니다.
- 검색창에 키워드를 입력하고 검색을 실행시키면 키워드에 해당되는 템플릿이 검색 됩니다.
- 마찬가지로 검색된 템플릿을 선택하고 열기를 하면 선택한 템플릿이 열립니다.
- 즐겨찾기 기능
- 자주 여는 템플릿을 즐겨찾기로 추가하여 관리할수 있습니다.
- 물론 파일로 저장하여 관리하여도 무방합니다. — --->즐겨찾기 추가에서 새그룹으로 트리를 만들어
- 저장할수 있으며 원치 않을때는 추가만으로도
- 즐겨찾기로 저장하여 사용 가능합니다.
- 시세성 데이터 — 메모리성 데이터로서 실시간 연동 되는 데이터를 조회 시 사용합니다.
- 일별 데이터 — 일별추이 조회 시 사용합니다.
- Tick 시계열 — Tick 데이터를 일정시간 혹은 기간동안의 추이 데이터를 불러 올 때 사용합니다.
- Intra 시계열 — 주기데이터를 일정시간 혹은 기간동안의 추이 데이터를 불러올때 사용합니다.
- 특이조회 — 거래량 상위,상승률 상위 같은 순위 데이터를 조회 시 사용합니다.
- 함수/지표 조회 — CHECK화면상의 데이터를 엑셀로 불러 올때 사용합니다.
- 재무 데이터 — 각기업의 재무재표 조회시 사용합니다.
- 엑셀 내 함수 입력으로 조회 하거나 기존 파일의 종목을 변경하기 위해 종목 검색창을 선택할 수 있습니다.
- 종목검색창에서 한 개 혹은 그 이상을 선택하거나 블록을 지정하여 원하는 위치에 드래그 앤 드롭 해줍니다.
- 혹은 더블 클릭으로 선택된 종목을 엑셀에 보여줍니다.
- 종목 검색창 하단에 있는 옵션에 따라 종목코드의 세로 배치/ 가로 배치와 종목명 표시 여부를 선택할 수 있습니다.
- 데이터 연동을 위해서 가져오려는 정보 항목을 선택할수 있어야 합니다. 항목 검색창은 정보 항목을 검색하여 엑셀에 출력할수 있습니다.
- 정보 항목검색이 가능하며 Data조회의 위자드에서 저장한 즐겨찾기 항목을 선택할수도 있스빈다.
- 데이터의 속성에 따라 실시간/일별/틱시계열/인트라/재무데이터로
- 나눠지며 원하는 정보 형식을 선택하시면 됩니다.
- 데이터의 속성을 설정한 후 원하는 시장을 선택하여 그에 맞는
- 정보항목을 선택할수 있습니다.
- ▶항목을 엑셀에 추가할 경우는 아래 그림과 같이 블록을 지정하여 드래그& 드롭하거나 선택한 후 확인 버튼을 눌러 추가합니다.
- 항목을 추가할때는 반드시 항목 세로 배치 옵션에 체크를 뺀상태로 옮기거나 환경설정창에서 종목배치 방식을 가로로 변경하여야 만 합니다.
- 항목 검색창에서 검색어 입력하여 원하는 항목을 찾을 수 있습니다.
- Data조회시 항목을 즐겨찾기 했을 경우 항목검색창의 즐겨찾기 탭에서 볼수 있습니다.
- 사용자가 직접 함수를 이용하여 원하는 데이터를 조회 /가공 할수 있습니다.

- CH,CIS,CLIST,CT,CTD,CTR,CTS 로 구성되어 있습니다.
- 자세한 함수 설명은 함수 설명 페이지에서 보실수 있습니다.
- 엑셀에 출력된 데이터로 범위를 지정하여 차트를 쉽게 만들 수 있습니다.
- 차트 만들기 위한 범위를 지정한 후 마우스 우측 버튼 클릭으로 ezChart
- 선택하면 차트가 그려지고 차트 설정을 바꿀수 있는 차트 마법사가
- 생성되어 차트 유형이나 레이블의 설정을 변경 할수 있습니다.
- 종목 검색창과 항목검색창을 각각 선택하여 종목과 항목을 셀에 추가 한후 왼쪽 셀을 클릭하여 테이블 조회를 선택하면
- 선택된 셀을 중심으로 우하향 하면서 종목코드와 항목코드를 참조하여 데이터 연동이 일어 납니다.
- 각 셀을 클릭하면 CT함수가 자동적으로 입력된 것을 확인 할 수 있습니다.
- 이렇게 만들어진 파일은 저장한 후 열면 데이터를 실시간으로 받습니다. 추후로 종목이나 원하는 항목을 바꿔주면 실시간으로
- 셀참조가 이뤄져서 데이터가 조회 됩니다.
