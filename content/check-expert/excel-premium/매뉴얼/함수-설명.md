# 함수 설명

> 출처: `excel-manual2_function.xls`. 그림과 도형은 원본 Excel 파일에서 확인하세요.

## 함수설명

- 엑셀 프리미엄을 이용해주셔서 감사합니다.
- 엑셀 프리미엄 함수는 다음의 공통점을 지니고 있어 이 점만 기억하시면 엑셀 프리미엄 함수를 매우 쉽게 활용하실 수 있습니다.
- (1) 모든 함수의 핵심은 "종목코드" 와 "항목코드" 입니다.
- 종목코드와 항콕코드는 직접 타이핑 할 수도 있지만 셀참조를 이용하실 수 있습니다.
- (2) 종목코드와 항목코드를 찾는 법은 다음과 같습니다.
- 엑셀 상단의 [XL Pemium] 탭 > [종목검색], [항목검색] > 원하시는 종목 또는 항목을 검색하시면 됩니다.
- ※종목코드를 확인하실 수 있습니다. — ※FID가 항목코드입니다. (alias는 별칭입니다)
- 실시간 시세표를 만들 때 이용됩니다.
- =CT("종목정보", "항목정보") — → CT함수는 항목정보에 코드 뿐 아니라 명칭, alias도 입력 가능합니다.
- [사례1] 다음의 시세표를 완성해 보겠습니다.
- ※ 005930은 종목코드, PRICE와 15001은 '현재가'의 alias와 항목코드입니다.
- (1) 종목코드와 항목코드를 이용하는 방법 — (3) 종목코드와 Alias를 이용하는 방법
- =CT("005930","15001") — =CT("005930","PRICE")
- (2) 종목코드과 항목명을 이용하는 방법 — (4) 셀참조를 이용하는 방법
- =CT("005930","현재가") — =CT(A4,B2)
- [또다른 방법] 엑셀프리미엄에서는 "테이블조회" 라는 기능을 이용하여 쉽게 CT함수를 구현가능합니다.
- 을 셀선택 한 후,
- [XL Premium}탭 > "테이블조회" 클릭
- → 우측과 같이 자동으로 함수 및 값이 — ⇒
- 생성됩니다.
- [잠깐!] 값이 나오지 않는 경우, "설정" 에서 "테이블조회" 설정을 세로 ↔ 가로 로 변경해보시기 바랍니다.
- 특정 시점 혹은 특정기간동안의 값, 합계, 최대값, 상관관계 등을 산출할 수 있습니다.
- =CTD("세부함수명","종목코드","원하는 일자 혹은 기간","항목코드")
- 로 구성되어 있으며, 세부함수명에 따라 일자 또는 기간을 입력하게 됩니다. 예시를 잘 확인해주세요.
- [세부함수명에 따른 사례]
- [SPT] SK하이닉스의 2017.5.4 특정시점의 현재가, 대비, 등락률을 알고 싶은 경우
- =CTD("SPT","000660","20170504","15001")
- [SUM] SK하이닉스의 2019.8.1~8.7 동안의 거래량 합은? (거래량 항목코드:15015)
- =CTD("SUM","000660","20190801","20190807","15015")
- [MAX] SK하이닉스의 2019.8.1~8.31 동안의 종가중 최고가를 알고 싶은 경우
- =CTD("MAX","000660","20190801","20190831","15001")
- [MAXDATE] SK하이닉스의 2019.8.1~8.31 중 종가로 최고가를 기록한 날짜를 알고 싶은 경우
- =CTD("MAXDATE","000660","20190801","20190831","15001")
- [MIN] SK하이닉스의 2019.8.1~8.31 동안의 종가중 최저가를 알고 싶은 경우
- =CTD("MIN","000660","20190801","20190831","15001")
- [MINDATE] SK하이닉스의 2019.8.1~8.31 중 종가로 최저가를 기록한 날짜를 알고 싶은 경우
- =CTD("MINDATE","000660","20190801","20190831","15001")
- [AVG] SK하이닉스의 2019.8.1~8.31 동안의 평균가격을 알고 싶은 경우
- =CTD("AVG","000660","20190801","20190831","15001")
- [RATE] SK하이닉스의 2019.8.1~8.31 동안의 가격 변동률을 알고 싶은 경우
- =CTD("RATE","000660","20190801","20190831","15001")
- [RRATE] 삼성전자 대비 SK하이닉스의 2019.8.1~8.31 동안의 상대변화율을 알고 싶은 경우
- =CTD("RRATE","000660","005930","20190801","20190831","15001")
- [RANKING] SK하이닉스의 지금 현재 가격이 2019.8.1~8.31 의 가격들 중 몇순위인지 궁금할 때
- =CTD("RANKING","000660","20190801","20190831","15001","CT("000660","15001")")
- [DIFF] 2019.8.1을 기준으로 2019.8.31의 SK하이닉스의 대비값 (얼마나 상승 혹은 하락했는지)이 궁금할 때
- =CTD("DIFF","000660","20190801","20190831","15001")
- [STDEV] 2019.8.1~2019.8.31 동안의 SK하이닉스 주가 표준편차를 알고 싶을 때
- =CTD("STDEV","000660","20190801","20190831","15001")
- [잠깐! CTD함수에서 YYYYMMDD형식 외에 날짜를 지정하는 팁] → 우측표 참조 — ※현재를 기준으로 날짜지정하기
- [사례1] SK하이닉스의 15개월 전 현재가를 알고 싶은 경우
- =CTD("SPT","000660","15M","15001")
- [사례2] SK하이닉스의 2분기 전의 최초일자부터 현재까지의 주가 평균은,
- =CTD("AVG","000660","2QS","CUR","15001")
- 실시간 데이터를 시계열로 나열하는 함수
- =CTS("시작일자","종료일자",조회데이터수,화면표시갯수,실시간여부,"종목들","항목들",
- "정렬기준","공통옵션")
- 시작일자, 종료일자 : YYYYMMDD의 형식으로 입력합니다. (빈 따옴표("")는 오늘을 의미합니다.)
- 필요한 데이터 갯수를 입력하며 두 파라미터의 값은 같은 값으로 입력합니다.
- ※데이터 가공 및 함수개발을 위해 파라미터를 별개로 설정해야 합니다.
- 실시간여부 : 실시간으로 새 데이터가 갱신되길 원하시면 TRUE, 아니면 FALSE를 입력합니다.
- 종목들 : 다수의 종목코드 입력이 가능하며, "와 쉼표(,)로 구분합니다. ("005930,000660,005380")
- 항목들 : 다수의 항목코드 입력이 가능하며, "와 쉼표(.)로 구분합니다. ("15001,15015,15007")
- 정렬기준 : 내림차순(DESC), 오름차순(ASC)
- 공통옵션 : 출력방향(가로,세로), 데이터의 병합방식 등을 정하며, 마지막 페이지에 자세한 설명이 있습니다.
- [사례] 달러-엔 환율과 달러-원 환율의 최우선매도호가(14501) 최우선매수호가(14531)의 최근 10개 데이터를 실시간으로 보고 싶을 때
- =CTS("","",10,10,TRUE,"JPYUS,USDVS","14501,14531","DESC","NULL=DEFAULT; JOIN=MAIN; DIRECTION=VERT;
- TITLE=SUBJECT+ITEM, WITHTABLE=FALSE;")
- 틱(체결) 데이터를 일정한 주기로 묶어 가공하고 시계열 형태로 출력하는 함수
- =CIS("시작일자","종료일자",조회데이터수,화면표시갯수,주기,실시간여부,"종목들","항목들","정렬기준","공통옵션")
- 주기 : 출력할 데이터의 주기를 입력합니다.(10초(10S), 1분(1M), 1시간(1H))
- [사례] 삼성전자와 SK하이닉스의 현재가,거래량을 10초 단위로 최근 10개의 시계열 데이터를 출력하고 싶을 때
- =CIS("", "",10,10,"10S",TRUE,"005930,000660","15001,15015","DESC","NULL-DEFAULT; JOIN=MAIN;
- DIRECTION=VERT; TITLE=SUBJECT+ITEM; WITHTABLE=FALSE;")
- 특정 주기로 일간 시계열 데이터를 조회하는 함수
- =CH("시작일자", "종료일자",조회데이터개수,"주기",실시간 여부,"종목들","항목들","정렬방식","공통옵션")
- [사례] 삼성전자와 SK하이닉스의 현재가(종가)와 거래량을 최근 10일치 출력하고 싶을 때
- =CH(" "," ",10,"1D",TRUE,"005930, 000660","15001,15015","AND","NULL=DEFAULT; SORT=DESC; DIRECTION=VERT;
- TITLE=SUBJECT+ITEM; WITHTABLE=FALSE;")
- CHECK의 특정화면을 엑셀로 옮겨놓는 함수 (재조회시마다 데이터 갱신됨)
- 화면마다 CTR함수의 파라미터가 다를 수 있으므로,
- 처음부터 함수를 작성하기 보다는 참고할 화면에서 "엑셀 Premium으로 보내기"를 통해 함수를 확인하고
- 각 파라미터를 편집하길 권장드립니다.
- [사례] #1543화면
- CTR("TR번호", "SUB TR번호", 파라미터들 가변, "공통옵션")
- =CTR("154300","0","005930","20190801","20190831","1*002","-1","WITHTABLE=TRUE; DIRECTION=VERT; TITLE=ITEM+SUBJECT;")
- ※해석: 1543화면에서 "엑셀 Premium으로 보내기"를 클릭함
- 2019.8.1~8.31 동안 삼성전자와 KOSPI지수간의 누적수익률 비교
- 특이조회 사항들을 조회 합니다.
- =CLIST("시작일자","종료일자",조회데이터개수,"그룹","정렬기준 항목코드","특이 항목코드","항목들","공통옵션")
- 시작일자, 종료일자 : — 특정 기간의 주기별 데이터를 조회할때 입력합니다.
- 조회 데이터수 : 엑셀에 조회되어 표시되는 데이터 갯수입니다.(두항목 동일한 값을 입력합니다.)
- 그룹 : 어떤 그룹내에서 순위를 정하는 것인지 정해줍니다.
- 주식(전체 또는 업종별) → (예시. 코스피시장(K001), 코스닥시장(Q001))
- 정렬기준 항목코드 : 순위로 나열시 정렬기준으로 삼을 항목코드를 입력합니다.
- 특이 항목코드 : 상한가, 하한가, 최고가 등 (특이 항목) 을 조회시 입력하며 빈칸으로 두어도 무방합니다.
- 항목들 : 순위대로 나오는 종목들에 대해 출력되어야 할 항목들을 항목코드 형식으로 입력합니다.
- 공통옵션:엑셀을 화면에 표시하는 옵션입니다. 공통옵션 설명을 참조하세요.
- [사례] KOSPI 소속 종목들을 시가총액 순으로 나열하고, 그 종목들의 현재가와 시가총액을 알고 싶음
- =CLIST("","",10,"K001","15028","","15001, 15028","DESC","NULL=DEFAULT; DIRECTION=VERT;
- TITLE=SUBJECT+ITEM; WITHTABLE=TRUE; JOIN=MAIN;")
- SORT : 오름차순(ASC), 내림차순(DESC) — 오름차순, 내림차순 정렬
- NULL : 데이터의 값이 NULL값일 때, 처리 방법
- - DEFAULT : 설정파일에 항목코드별로 설정되어 있는 일간, 일중 처리 방법을 따름
- - PREV : 직전값을 가져옴
- - BLANK : 공백으로 남겨둠
- DIRECTION : 데이터의 출력 방향을 설정합니다.
- - 세로방향(VERT), 가로방향(HORZ)
- TITLE : 테이블 형태를 설정합니다.
- - SUBJECT+ITEM : 종목코드와 항목 출력
- - SUBJECT : 종목코드출력
- - ITEM : 항목 출력
- WITHTABLE : 출력되는 테이블을 함수의 삭제와 함께 처리
- - 삭제(TRUE), 삭제처리 안함(FALSE)
- JOIN : 병합방식으로서, 영업일자가 다른 종목들을 함께 조회할 것을 대비한 파라미터임.
- - MAIN : 첫번째 종목의 영업일 에 맞춰 데이터를 출력합니다.
- - AND : 모든 종목의 공통된 영업일 데이터를 출력합니다.
- - OR : 모든 종목의 모든 영업일 데이터를 출력합니다.
