# 4255 - 종목사전공시

> 출처: `CHECKPlus_Manual.pdf`, PDF 291-292쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
프로그램 매도/매수잔량 및 만기일 프로그램매매 사전공시 현황을 제공합니다.
## 화면 설명

### 화면 항목 1. 다음 순위의 종목들을 조회하는 연속 버튼입니다.

### 화면 항목 2. 자동 재조회 버튼
• 파란색으로 되어있을 경우 자동 재조회 해제 상태입니다.
• 자동 재조회 버튼을 클릭시 1분마다 순매수잔량을 기준으로 자동 정렬 됩니다.

### 화면 항목 3. 순매수 추정
• 사전(신규) 공시 : 프로그램매매 공시 신규 제출분
• 사전(정정) 공시 : 기 제출된 프로그램매매 공시에 대한 정정
• 사후(신규) 공시 : 호가불균형 발생시 사후 신고
• 프로그램매매 잔량은 프로그램 호가의 미체결잔량을 의미합니다.• 만기일 2시 50부부터는 공시된 수량들이 주문수량을 전환되므로 순매수추정 수량이 중복계산됩니다.
• 모든 데이터 컬럼의 컬럼명을 더블클릭하면 오름차순 또는 내림차순으로 정렬됩니다.
