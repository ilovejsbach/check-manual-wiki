# 4315 - Tick차트

> 출처: `CHECKPlus_Manual.pdf`, PDF 257-258쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
지수(KOSPI200, MINI KOSPI200, KOSDAQ150), 변동성지수, 섹터지수, 개별주식선물의 실시간 시장/이론 Basis,
체결량, 미결제량을 차트로 제공합니다.
## 화면 설명

### 화면 항목 1. 기준가 Check Box
• 기준가 Check를 하면 당일 기준Basis(선물기준가 - 기초자산기준가)가 하단 차트에 표시됩니다.

### 화면 항목 2. 시장 Basis 또는 이론 Basis 선택 버튼
• Basis는 기초자산의 가격이 변경되거나 선물의 체결이 발생할때마다 계산됩니다.

### 화면 항목 3. 계약수는 당일의 선물 누적계약수를 의미합니다.

### 화면 항목 4. 계약수는 실시간 체결량을 의미합니다.## 관련 화면
