# 4323 - 종합일별

> 출처: `CHECKPlus_Manual.pdf`, PDF 267-268쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
KOSPI200, MINI KOSPI200 선물의 일별 매도/매수 최우선호가, KOSPI200 매도/매수 호가지수, 시장/이론 Basis
데이터를 제공합니다. Basis는 선물종료 시점과 현물종료 시점을 구분 제공합니다.
## 화면 설명

### 화면 항목 1. 계산 기준시간 선택 버튼
• 선물종료 선택시에는 선물시장 종료시점을 기준으로 베이시스가 계산되며, 현물종료 선택시에는 현물(주식)시장 종료시점
을 기준으로 베이시스가 계산됩니다.

### 화면 항목 2. 선물
• 상단의 기준시간 선택 버튼에서 선택된 조건과 상관없이 선물 최종 가격을 제공합니다.
• 매도는 매도우선호가, 현재는 현재가, 매수는 매수우선호가, 이론은 이론가를 의미합니다.### 화면 항목 3. KOSPI200 지수
• 상단의 기준시간 선택 버튼에서 선택된 조건과 상관없이 최종 지수를 제공합니다.
• 매도는 매도우선호가, 현재는 현재가, 매수는 매수우선호가를 의미합니다.
