# 4132 - 매매단위

> 출처: `CHECKPlus_Manual.pdf`, PDF 198-199쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
당일의 체결내역을 매수체결, 매도체결로 나누어 분석하고, 체결수량별 비중을 제공합니다.
## 화면 설명

### 화면 항목 1. 매수체결 비중
• 당일의 총거래량 중에서 매수체결 성향을 갖는 체결량의 비중을 의미합니다. 동시호가때 체결된 수량은 제외됩니다.

### 화면 항목 2. 매도체결 비중
• 당일의 총거래량 중에서 매도체결 성향을 갖는 체결량의 비중을 의미합니다. 동시호가때 체결된 수량은 제외됩니다.

### 화면 항목 3. 체결수량별 비중
• 체결수량 구간대별 비중을 의미합니다. 예를 들어, 위의 화면에서 10~19계약이 동시에 체결된 건수는 34건이며, 총 수량은390계약입니다.
