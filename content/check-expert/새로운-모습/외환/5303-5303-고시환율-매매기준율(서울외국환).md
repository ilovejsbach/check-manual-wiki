# 5303 - 고시환율>매매기준율(서울외국환)

> 출처: `CHECKPlus_Manual.pdf`, PDF 752-754쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

- TR 5301 — 고시환율>고시환율 일중추이(외환은행)
## 화면 개요
서울외국환중개에서 제공하는 매매기준율을 제공합니다.
## 화면 설명

### 화면 항목 1. 서울외국환중개에서 발표하는 통화별 매매기준율을 제공합니다.

### 화면 항목 2. 기준일에 해당하는 매매기준율 데이터가 오전 8시 50분 이전에 업데이트 됩니다.

### 화면 항목 3. 통화명

ARS : Argentine Peso
AUD : Australiam Dollar

BDT : Bangladesh Taka
