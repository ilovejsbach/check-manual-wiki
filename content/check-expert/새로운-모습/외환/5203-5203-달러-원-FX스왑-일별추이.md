# 5203 - 달러-원 FX스왑>일별추이

> 출처: `CHECKPlus_Manual.pdf`, PDF 742-743쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
달러-원 FX스왑의 일별추이 데이터를 조회 할 수 있습니다. (단위 : BP)
## 화면 설명

### 화면 항목 1. 만기, 조회기간 선택
원하는 만기에 대해 선택하여 조회합니다.
조회기간에 대해 From~To 를 설정하여 조회합니다.

### 화면 항목 2. 데이터/차트/혼합 선택 기능
데이터만 보여주는 화면, 차트만 보여주는 화면, 데이터와 차트를 동시에 보여주는 화면을
해당하는 버튼을 클릭하여 조회 할 수 있습니다.

### 화면 항목 3. 결제일선택된 만기유형에 따라 결제일이 일별로 제공됩니다.
SPOT(현재가) = T+2
O/N(Over Night) = T+1
T/N(Tomorrow Next) = T+1 시점에서 T+2일까지
1W(Week) = T+2(SPOT) + 7
1M(Month) = T+2(SPOT) + 30
Y(Year) = T+2(SPOT) + 365
