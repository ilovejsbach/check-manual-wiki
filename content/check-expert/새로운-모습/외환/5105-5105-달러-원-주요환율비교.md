# 5105 - 달러-원>주요환율비교

> 출처: `CHECKPlus_Manual.pdf`, PDF 734-735쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
달러-원 환율과 해외환율을 비교하는 화면입니다.
## 화면 설명

### 화면 항목 1. 해외환율 선택
콤보를 눌러 해외환율을 선택할 수 있습니다.
선택된 환율은 달러-원환율과 차트에서 비교할 수 있도록 제공됩니다.

### 화면 항목 2. 비교차트 선택기능 제공

상단에 조회된 환율에 대해서 원하는 조합으로 비교차트를 조회할 수 있습니다.- TR 5100 — 달러-원>종합화면
- TR 5101 — 달러-원>현재가
- TR 5103 — 달러-원>일별추이
- TR 5106 — 달러-원>Tick차트
- TR 5107 — 달러-원>1분차트
- TR 5108 — 달러-원>일봉차트
- TR 5109 — 달러-원>지표종합
- TR 5501 — 해외SPOT>현재가(주요)
