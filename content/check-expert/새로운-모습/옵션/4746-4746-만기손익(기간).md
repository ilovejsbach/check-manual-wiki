# 4746 - 만기손익(기간)

> 출처: `CHECKPlus_Manual.pdf`, PDF 405-406쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
투자주체별 KOSPI200 선물/옵션 기간합산 만기손익 추정치를 제공합니다.
## 화면 설명

### 화면 항목 1. 옵션 월물 선택 콤보
• 콤보에서 선택된 월물의 옵션들을 이용하여 투자자별 만기손익을 추정합니다.

### 화면 항목 2. 지수범위
• 차트에서 조회할 지수 범위를 입력합니다. X축으로 표시됩니다.

### 화면 항목 3. 손익분기• 투자주체별 만기손익이 0이 되는 지수입니다.
