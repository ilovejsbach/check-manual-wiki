# 4571 - 종목일별

> 출처: `CHECKPlus_Manual.pdf`, PDF 377-378쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
옵션 종목별 체결내역, 시세성향, 민감도, 평균단가, 협의대량 정보를 제공합니다.
## 화면 설명

### 화면 항목 1. 조회 항목 선택 버튼
• 체결내역 : 시가/고가/저가, 거래량, 거래대금, 내재변동성, 미결제량, 기초자산 종가
• 시세성향 : 거래량, 매수체결, 매도체결
• 민감도 : 델타, 감마, 베가, 세타, 로우, 내재변동성
• 평균단가 : 평균단가, 미결제수량, 기초자산 종가
• 협의대량 : 거래량, 거래대금, 협의대량계약수- TR 4551 — 종목일중
- TR 4589 — 일별편집
- TR 4599 — 과거종목
