# 페이지 저장하기

> 출처: `CHECKPlus_Manual.pdf`, PDF 55-56쪽. 자동 추출 문서이므로 도표와 화면 이미지는 원본을 함께 확인하세요.

4. PAGE 저장
페이지 저장하기

1) 페이지 화면이란?
화면 자체를 사용자가 보고 싶어하는 화면 배치 및 화면 조회 상태로 미리 만들어 두고 그 상태 그대로 다시 오픈하여
조회할 수 있는 기능입니다. 자주 사용하는 여러 화면들을 하나의 Page 화면으로 저장하면 나중에 동일한 화면 구성
으로 신속한 조회가 가능합니다.
- 저장 대상 범위 : 화면코드, 화면위치, 조회된 종목, 화면셋팅 정보(컨트롤)

2) 페이지 화면 등록하기
1 Page 화면으로 만들고 싶은 화면을 원하는 배열 상태로 구성합니다.
2 기능>9008 페이지 화면 선택 or 키보드 단축키 F2 실행 or 즐겨찾기바의 을 클릭하여
페이지를 저장합니다.

이 때 페이지로 저장되는 화면번호는 0201 ~ 0299까지 사용가능합니다.

<small>원본 PDF 55쪽</small>

PAGE 저장

3) 페이지 화면 수정 및 삭제 하기
1 PAGE 목록편집창을 열어(키보드 단축키 F2) 수정하고자하는 화면번호가 있는 행을 선택합니다.
2 화면명란에 수정하고자 하는 화면명을 입력합니다.
3 버튼을 클릭하고 버튼을 클릭하여 저장합니다.
4 삭제하고자 하는 화면번호가 있는 행을 선택한 후 버튼을 클릭하고 버튼을
클릭하여 저장합니다.

4) 페이지 화면 조회하기
Case1) Page 화면번호를 "화면번호 입력창"에 입력하면 (예 : 0201) 화면이 바로 조회됩니다.

Case2) 즐겨찾기바에 저장된 아이콘을 클릭하여 바로 화면을 오픈합니다.
