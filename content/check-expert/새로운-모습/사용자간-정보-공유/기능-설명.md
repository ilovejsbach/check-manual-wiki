# 기능 설명

> 출처: `CHECKPlus_Manual.pdf`, PDF 21-23쪽. 자동 추출 문서이므로 도표와 화면 이미지는 원본을 함께 확인하세요.

4. 사용자간 정보 공유
기능 개요
CHECK 사용자간 나의 정보를 다른사람에게 전송하고 또한 다른사람으로부터
정보를 수신받을 수 있습니다.
지금까지 불편한 방식으로 정보를 공유하셨다면 이제는 CHECK단말내에서 마우스클릭만으로 쉽게 정보를 공유할
수 있습니다.
기능 설명

1) 관심종목 공유

다른 사람에게 나의 관심그룹 내 관심종목들을 한번에 전송하고 수신받을 수 있습니다.

<small>원본 PDF 21쪽</small>

사용자간 정보 공유
1 공유대상 관심그룹 선택
관심그룹편집창에서 등록한 관심그룹리스트가 조회되고 공유하고자 하는 관심그룹을 선택합니다.
2 단말 ID 입력
전송하고자 하는 단말 ID 10자리를 입력합니다. 를 클릭하면 단말 ID를 확인하는 방법이
안내되어 있습니다.
주로 공유하는 대상자가 정해져 있다면 단말 ID를 그룹화하여 저장해놓고 사용하는것이 편리합니다.
3 공유메시지 작성
공유메시지를 작성하면 상대방의 단말 팝업창에 해당 메시지가 표시됩니다.
4 공유
를 클릭하면 나의 관심종목이 상대방에게 전송됩니다.
기존에 관심그룹을 2개 가지고 있던 사람이 다른사람으로부터 관심그룹을 3개 수신 받으면 총 5개의 관심그룹이 생
성됩니다.

2) 통합환경설정 공유

다른 사람에게 나의 통합환경설정정보를 한번에 전송하고 수신받을 수 있습니다.

<small>원본 PDF 22쪽</small>

기능 설명 | 23
1 공유대상 정보 중 통합환경설정정보 선택
2 공유대상 단말 ID 입력
3 공유 메시지 작성
4 공유 버튼 클릭하여 상대방에게 나의 통합환경설정정보 전송
통합환경설정정보를 수신받는 경우 기존에 셋팅한 정보는 없어지고 새로 수신한 환경설정으로 업데이트 됩니다.
구체적으로 본인이 기존에 저장해둔 즐겨찾기바의 화면, 페이지 등이 수신받은 정보로 변경되니 주의하시기 바랍니

다.
