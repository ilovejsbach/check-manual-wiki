# 엑셀데이터 연결하기

> 출처: `CHECKPlus_Manual.pdf`, PDF 38-39쪽. 자동 추출 문서이므로 도표와 화면 이미지는 원본을 함께 확인하세요.

2. 엑셀데이터 연결
엑셀데이터 연결하기

1) 화면에서 실시간 엑셀 연동(RTD) 하기
화면에서 엑셀로 실시간 데이터를 보내는 방식은 화면에서 마우스 우측버튼을 팝업하여 "엑셀실시간 붙여넣기"를 실행하거나,
화면에서 엑셀로 보낼 영역을 마우스로 블럭지정한 후 Alt 키와 마우스 왼쪽 버튼을 클릭된 상태로 드래그합니다.

2) 엑셀 편집창을 이용하여 데이터 연동하기
단축키 F3을 누르면 다음과 같이 엑셀에서 조회하고자 하는 종목과 항목을 선택할 수 있는 편집창이

팝업됩니다.

<small>원본 PDF 38쪽</small>

엑셀데이터 연결하기 | 39
1 종목을 바로 입력하거나 "검색" 버튼을 눌러 종목검색창에서 원하는 종목을 선택합니다.
2 조회하고자 하는 정보항목을 분류에서 선택하면 선택된 정보항목 리스트가 표시됩니다.
3 '엑셀로' 버튼을 클릭하면 선택된 종목과 항목이 엑셀에 실시간으로 표시됩니다.

3) 엑셀 프리미엄 서비스를 이용하여 데이터 연동하기
엑셀프리미엄 서비스는 CHECKExpert+의 데이터를 엑셀과 연동시켜 사용자가 직접 데이터를 다양하게 가공할 수 있는 기능

을 제공합니다.
