# 3747 - 시가평가 > CD/CP > CD/CP 개별기업별 수익률

> 출처: `CHECKPlus_Manual.pdf`, PDF 685-686쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
● 한국예탁결제원에서 제공하는 기업어음(CP) 발행정보를 조회할 수 있습니다.
## 화면 설명

### 화면 항목 1. 날짜를 선택합니다.

### 화면 항목 2. 평가기관을 선택합니다. 민평(3사), 민평(4사), KIS, 한국, NICE, FN

### 화면 항목 3. 수익률, 기준등급대비 중에서 조회할 데이터를 선택합니다.

### 화면 항목 4. CD, CP 등급별 채권평가사별로 평가하는 개별기업의 갯수를 표시합니다.
등급 더블클릭시 민평3사 평균 수익률이 조회되며, 각 평가사별 기업의 개수 클릭시
해당 평가사의 수익률이 조회됩니다.

### 화면 항목 5. 선택된 등급 소속 상세 기업에 대한 수익률이 제공됩니다.

### 화면 항목 6. 우측상단에서 더블클릭한 기업에 대한 수익률의 시계열 추이가 제공됩니다.만기 헤더의 체크박스를 체크하면 우측 차트에서 조회할 수 있습니다.

### 화면 항목 7. 6 번 그리드에서 체크한 만기의 시계열이 차트로 그려집니다.
