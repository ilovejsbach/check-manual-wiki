## 화면 개요
● 해외 30여개 주요국의 국채금리를 24시간 실시간으로 제공합니다.
## 화면 설명

### 화면 항목 1. 기준일을 선택합니다. 기본 설정은 당일입니다.

### 화면 항목 2. 하단에서 조회할 시세표의 레이아웃을 선택합니다.
- MID/대비 : MID 및 대비를 표시합니다.
- BID/ASK : BID와 ASK를 표시합니다.

### 화면 항목 3. 국가별 만기별 실시간 시세를 제공합니다.
- 제공국가
· 아시아 : 한국, 일본, 중국, 홍콩, 대만, 필리핀, 태국, 말레이시아, 싱가폴, 인도, 인도네시아
· 아메리카 : 미국, 캐나다, 멕시코, 브라질
· 유럽 : 영국, 프랑스, 독일, 네덜란드, 덴마크, 벨기에, 노르웨이, 스웨덴, 포르투갈, 그리스,
이탈리아, 헝가리, 폴란드, 터키, 남아공
· 오세아니아 : 호주, 뉴질랜드
