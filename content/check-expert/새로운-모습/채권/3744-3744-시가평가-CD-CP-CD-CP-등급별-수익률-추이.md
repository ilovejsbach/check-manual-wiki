# 3744 - 시가평가 > CD/CP > CD/CP 등급별 수익률 추이

> 출처: `CHECKPlus_Manual.pdf`, PDF 683-684쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
● 시가평가사에서 산출하는 CD/CP 등급별/만기별 수익률 추이를 제공합니다.
## 화면 설명

### 화면 항목 1. 조회기간을 설정합니다. 기본설정은 3개월전 ~ 당일입니다.

### 화면 항목 2. 채권평가사를 선택합니다. 민평(3사), 민평(4사), KIS, NICE, 한국, FN

### 화면 항목 3. CD, CP 등급 구분을 선택합니다.
- CD : AAA, AA+, AA0, AA-, A+, A0, A-, BBB
- CP : A1, A2+, A2, A2-, A3+, A3, A3-

### 화면 항목 4. 만기별 시계열 추이를 조회합니다. 그리드 헤더에 체크한 지표에 대해서 하단 6 번 영역에서차트로 조회할 수 있습니다.

### 화면 항목 5. 상단에서 조회한 만기별 시계열 추이의 통계 정보(최대값, 최소값, 평균값)를 제공합니다.

### 화면 항목 6. 4 번에서 체크한 지표들의 추이를 조회합니다.
