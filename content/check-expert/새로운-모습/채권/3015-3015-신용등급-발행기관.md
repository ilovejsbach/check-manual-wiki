# 3015 - 신용등급 > 발행기관

> 출처: `CHECKPlus_Manual.pdf`, PDF 521-522쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
● 채권을 발행하는 발행기관의 신용등급(Issuer Rating)이 제공됩니다.
## 화면 설명

### 화면 항목 1. 발행기관코드를 입력합니다. 00000을 입력하면 전체 발행기관의 리스트를 조회 가능합니다.

### 화면 항목 2. 신용등급을 조회할 기간을 입력합니다. 기본설정은 3년전 ~ 당일입니다.

### 화면 항목 3. 등급의 범위를 지정 가능합니다. (AAA ~ D)

### 화면 항목 4. 신용평가기관을 선택합니다.

### 화면 항목 5. 평정구분을 선택합니다.### 화면 항목 6. Outlook 구분을 선택합니다.

### 화면 항목 7. 발행기관에 대한 평가사별 등급현황을 최근일순으로 조회합니다.
## 정보 사이트
NICE신용평가 : http://www.nicerating.com/
한국신용평가 : http://www.kisrating.com/

한국기업평가 : http://www.rating.co.kr/index.jsp
