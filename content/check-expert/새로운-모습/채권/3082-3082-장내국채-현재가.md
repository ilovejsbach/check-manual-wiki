# 3082 - 장내국채 > 현재가

> 출처: `CHECKPlus_Manual.pdf`, PDF 571-575쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
한국거래소(KRX)의 국채전문유통시장(KTS-KRX Trading System for government securities) 의 종목별 거래 정보를 종합
적으로 제공합니다.
## 화면 설명

### 화면 항목 1. 종목콤보 클릭으로 국고채 종목 선택을 쉽게 할 수 있습니다.### 화면 항목 2. 호가 3080(장내국채 6종목 호가창) 화면 연결
시세표 3083(장내국채 전종목 시세표) 화면 연결

### 화면 항목 3. 선택된 종목의 발행정보 조회(발행일, 만기일, 상장일, 상장액, 표면금리, 잔존일, 대용가, 기준가)

### 화면 항목 4. 선택된 종목의 현재 시세 조회(현재/시/고/저 가격 및 수익률, 민평대비 스프레드, 거래량 등)

### 화면 항목 5. 실시간 체결 Tick 정보 조회 및 체결성향(B, BB, S, SS) 제공
B 최우선 매도호가 체결 후 호가 변경 없음
BB 최우선 매도호가 체결 후 호가 변경 있거나 차우선 매도호가 체결

S 최우선 매수호가 체결 후 호가 변경 없음SS 최우선 매수호가 체결 후 호가 변경 있거나 차우선 매수호가 체결

### 화면 항목 6. 5단계 매수호가, 매도호가창 제공

### 화면 항목 7. 틱차트, 일별추이, 일별차트, 민평대비 스프레드, 거래비중, 매물대차트 제공
• 틱차트 : 실시간 체결 수익률/가격 및 거래량 차트 제공
• 일별추이 : 일별 종가 수익률/가격 및 거래량/거래대금 추이 제공
• 일별차트 : 일별 종가/수익률 봉차트 및 거래량 차트 제공• 민평SP : 일별 종가수익률과 민평 수익률과의 스프레드 차트 제공
• 거래비중 : 체결 가격대별 체결성향에 따른 매수거래량, 매도거래량 비중을 제공
조회버튼 클릭으로 현재시점 거래량으로 업데이트 가능함
• 매물대차트 : 체결 가격대별 매수거래량, 매도거래량을 차트로 제공
시간대별 체결가격추이도 함께 제공

조회버튼 클릭으로 현재시점 거래량으로 업데이트 가능함## 특이 사항
정보 제공 : 한국거래소, 코스콤, 채권평가사 4사
체결성향 정보는 CHECK 자체산출
