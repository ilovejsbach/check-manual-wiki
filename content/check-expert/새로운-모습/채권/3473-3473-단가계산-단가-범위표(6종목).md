# 3473 - 단가계산 > 단가 범위표(6종목)

> 출처: `CHECKPlus_Manual.pdf`, PDF 644-646쪽. 검색 가능한 본문과 원문 페이지 이미지를 함께 제공합니다.

## 화면 개요
● 6개 채권 종목에 대한 민평기준 +-15개 수익률/가격 범위의 단가계산 결과를 제공합니다.
## 화면 설명

### 화면 항목 1. 결제일을 선택합니다. 영업일기준 T, T+1, T+2일을 선택할 수 있습니다.

### 화면 항목 1. 번을 통해 선택한 결제일은 하단의 6개 결제일에 일괄 적용되며,

### 화면 항목 2. 번의 개별적인 캘린더를 통해 결제일을 별도로 지정할 수도 있습니다.

### 화면 항목 2. 각각의 해당 종목에 대한 계산의 기준이 되는 결제일을 설정합니다.

### 화면 항목 1. 번 버튼을 통해 자동으로 일괄 설정할 수도 있고, 캘린더에서 직접 설정할 수도 있습니다.

### 화면 항목 3. 종목을 선택합니다. 6개까지 선택할 수 있습니다.

### 화면 항목 4. 선택한 종목의 발행일, 만기일, 표면금리가 제공됩니다.
종목명을 더블클릭하면 3904 종목 요약정보 화면이 팝업됩니다.

### 화면 항목 5. FRN 종목 조회시 차차기 금리 에디트 박스가 활성화되며, 차차기 금리에 원하는 수익률을
입력하면, 해당 수익률을 반영한 현금흐름으로 단가계산이 됩니다.

### 화면 항목 6. 계산의 기준이 되는 수익률 및 단가를 입력합니다.

### 화면 항목 10. 번 영역에서 수익률(1bp), 수익률(0.1bp)가 선택되어있는 경우 수익률을
단가입력이 선택되어 있는 경우 단가를 입력합니다.

### 화면 항목 7. 수익률 → 단가, 단가 → 수익률의 계산 결과를 제공합니다.
- 10 번 영역에서 수익률(1bp), 수익률(0.1bp)가 선택되어있는 경우
수익률 → 단가 계산
- 10 번 영역에서 단가입력이 선택되어있는 경우
단가 → 수익률 계산
- 계산 결과에 대해서 직전대비, 기준값대비를 조회할 수 있습니다.

### 화면 항목 8. 6 번 영역의 에디트박에 입력된 수익률/단가를 7번 영역의 기준 값으로 설정합니다.

### 화면 항목 9. 12 번에서 선택된 민평 수익률/단가를 7번 영역의 기준 값으로 설정합니다.

### 화면 항목 10. 7 번 계산 결과 영역의 맨 왼쪽 열에 표시될 데이터를 선택합니다.

### 화면 항목 11. 10 번 영역에서 수익률(1bp), 수익률(0.1bp)가 선택되어있는 경우 활성화되며
수익률 → 단가 계산 결과 표시시 단가의 단위를 선택합니다. 1원, 0.1원, 0.01원

### 화면 항목 12. 화면 최초 오픈시, 민평입력 버튼 클릭시에 민평(3사), 민평(4사) 중에 선택합니다.

### 화면 항목 13. 7 번 영역의 대비값을 직전대비, 민평대비 중에 선택합니다.

### 화면 항목 14. 해당 화면을 인쇄합니다.

### 화면 항목 15. 6개 종목의 계산결과를 한개의 엑셀 시트로 보냅니다.

### 화면 항목 16. 해당 화면을 N*M 개로 확장합니다.
